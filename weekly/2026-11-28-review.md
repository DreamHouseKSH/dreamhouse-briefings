# 주간 정리 — 2026-11-28

> 대상은 2026-11-23(월)~11-27(금)의 한국시간 뉴스·GitHub 아카이브이며, 실제 작성·게시일은 11월 28일입니다. IT·AI·모델·엔진 20파일과 X 5파일, GitHub 5파일을 읽었습니다. 항목 수는 일별 파일을 기준으로 하며 여기서는 세지 않았습니다. 일별 파일에는 각 항목의 시간 판정이 남아 있습니다. 이 글은 월~금 아카이브의 재구성이며 전수 조사가 아닙니다. 직접 링크한 원문은 이 아카이브에서 확인한 것에 한하고, 링크가 없는 내용은 해당 일자 일별 판을 참조하세요. 회사 주장, 2차 매체 요약, 편집 해석을 구분했고 투자 조언이 아닙니다.

## 이번 주 흐름

### 복귀 랠리는 하루였다

주의 시작은 [CNBC가 전한 젠슨 황의 CEO 복귀](https://www.cnbc.com/2026/11/23/anthropic-nvidia-shares.html)였다. 엔비디아는 월요일 하루 31.48% 올랐고 나스닥은 6.51% 올랐다. 그러나 11-25 판이 후속으로 기록했듯 랠리는 하루 만에 반락했다. 엔비디아가 -6%, 반도체가 급락했고 11-26 판은 매도 3일째를 기록했다. 11-27 판에는 엔비디아가 동남아 4개국 서버 출하를 중단했다는 항목이 올랐고, 같은 날 The Neuron은 무디스의 등급 전망이 긍정적에서 안정적으로 낮아졌다고 전했다. 이 둘의 인과는 보도에서 확인되지 않는다. 월요일 판이 이미 짚었던 대로 복귀는 지배구조 이벤트였고, 지난주 매도의 배경인 밸류에이션 우려를 없애지 못했다.

### 에이전트의 접근권이 약관이 되었다

주 내내 같은 주제가 다른 얼굴로 나왔다. 월요일 [FourWeekMBA 브리프](https://fourweekmba.com/ai-morning-brief-22-nov-2026-musks-cash-warning-copilots-205/)가 전한 은행권의 '외부 에이전트의 행위는 고객 승인으로 간주' 약관, 화요일 Signal의 에이전트 접근 차단 강화(원 발표는 미확인), 목요일 MCP 두 돌과 Skills over MCP, 금요일 Google의 Workspace AI 부록(Real Python 요약 기준 2027-02-01 집행)이다. 그리고 OpenRouter가 프롬프트 탈취를 이유로 추론 제공사 3곳을 끊고 ZDR 표시를 뗀 것(Dragos 연구 인용)은 같은 주제의 반대편이다. 에이전트를 막는 쪽도, 열어 주는 쪽도, 쓰는 쪽도 각자 계약 문구를 쓰고 있다. 이 가운데 상당수는 2차 요약에 기대고 있어 원문 약관 확인이 다음 단계로 남는다.

### 수학 주장 두 가지, 검증의 속도 차이

11-23 판은 [Lean 커뮤니티의 공동 성명](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/)으로 리만가설 증명이 기계 검증을 받았다고 기록했다. 11-25 판은 MIT 검증 페이지에서 여러 커널이 익스포트를 수용했으나 비교기(comparator)는 아직 실행 중이라고 후속을 달았다. 반면 11-26 판의 OpenAI 수학 원고 9편(VP≠VNP, 행렬곱 지수 9/4 등)은 독립 검증이 없다. 같은 주에 한쪽은 기계가 검증하는 증명이고 다른 쪽은 아직 주장이다. 이 아카이브는 앞으로도 둘을 같은 줄에 세지 않는다.

## 분야별 정리

### IT — 이벤트와 정책이 시세를 흔든 주

월요일 [Benzinga 주간 결산](https://www.benzinga.com/markets/tech/26/11/63517079/nvidia-alibaba-walmart-pony-ai)이 엔비디아 실적과 황 퇴임 후 첫 분기를 정리했다. 수요일에는 Meta가 Muse를 인스타그램 DM에 통합하기 시작했고, CrowdStrike가 Zscaler를 440억 달러에 인수한다고 발표했다. 목요일에는 Dell이 AI 서버 수요로 기록적 분기를 냈으나 Morningstar가 적정가를 낮췄다는 점이 함께 기록됐다. 금요일에는 FCC가 스페이스X의 궤도 AI 데이터센터 'Starmind' 최대 100만 기 위성을 승인했고 OpenAI가 ChatGPT 사용량 한도 통합을 예고했다.

### AI — 승인과 책임의 위치

월요일 Obsidian의 Grok Bot 플러그인과 Hermes의 '선제 행동' PR은 모두 llmnet이 '중간' 신뢰도로 전했고, 두 항목 모두 사람의 승인 단계를 전제로 했다. 화요일에는 OpenAI 수석과학자의 '퍼플렉시티 공동 한계' 제안(llmnet 중간 신뢰도)과, 수요일 원문 확인으로 모델별 퍼플렉시티가 처음 공개됐다는 후속이 있었다. 금요일에는 Anthropic이 Messages API를 Python에서 Rust로 옮겼고, OpenClaw 2026.11.10이 나왔다. 같은 주 말 Real Python이 정리한 Anthropic의 Claude Ship(정책 파일이 허용하면 AI가 루틴 변경을 승인)은 위 흐름에서 승인의 책임을 팀의 정책 파일에 맡기는 쪽의 선택지다.

### 모델 — 루프 구조, 가격, 오픈 가중치

월요일 [Sarvam-105B-1711](https://www.sarvam.ai/blogs/sarvam-105b-1711)은 오픈웨이트 체크포인트로 소개됐다. 화요일 [Z.ai의 GLM-5.4](https://z.ai/blog/glm-5.4)는 첫 루프 트랜스포머 플래그십을 내세웠고 '2~3조 파라미터급 지능'을 주장했다(자사 주장). 수요일 Sand AI의 MAGI-2(480B MoE 비디오 생성)와 SenseTime의 SenseNova U1.6이 이어졌다. 목요일 JetBrains의 Mellum2.1 Instruct(12B MoE, Apache 2.0)와 PrismML의 Ternary Bonsai 2.5 27B가 소형·저비트 흐름을 이었다. 금요일에는 GigaChat 4, Ling-3.2-air, KRAFTON의 Raon-1 mini preview가 나왔고, 토요일 판이 후속으로 Raon-1 mini 정식판과 GigaChat 3.5 Omni를 다뤘다. 모든 벤치마크는 개발사 자체 수치다. 금요일 The Neuron은 Z.AI의 차기 플래그십 지연과 문샷의 릴리스 간격 확대를 로이터 인용으로 전했는데, 이는 같은 주 GLM-5.4 발표와 함께 읽어야 한다.

### 엔진 — 틀리거나 열려 있던 구멍

월요일 vLLM의 보안 수정 4건과 SGLang diffusion의 LoRA 조용한 실패(샘플의 14%) 차단, MLX의 빈 출력 세그폴트 수정이 나왔다. 화요일 llama.cpp의 토큰 인식 채팅 파싱과 MLX의 float32 누산이 이어졌다. 수요일에는 Ollama의 Inkling2 Metal 커널과 vLLM ROCm 프리필 최적화가, 목요일에는 vLLM의 미디어 페치 마감시간과 SGLang diffusion의 API 키 도입이 있었다. 금요일에는 llama.cpp named tool choice, vLLM·SGLang의 GLM-5.3-Flash 커널이 나왔다. 속도 개선(최대 38.37배 등)도 있었지만 '최대' 수치는 조건부이며, 기록에 남은 것은 대부분 오답·무인증 같은 구멍이었다. 일별 판은 RepoJournal 집계에 의존했고 PR 원문 확인은 제한적이었다.

### GitHub — 목록은 굳었고 1위는 하나

11-24 판은 닷새째 같은 16개를 기록했고 월요일에 증가량이 일제히 뛰었다. 수요일 판에서 목록이 교체됐고(BugHunter, stitch-skills, app-store-compliance, Ghost-Downloader-3, autoclip 카드) 그 뒤 금요일까지 같은 구성이 유지됐다. Claude-BugHunter는 수요일부터 1위였다. 이 아카이브의 규칙대로 목록의 교체는 인기의 소멸이 아니라 GitHub 관측 기간 갱신으로 읽는다. 라이선스 이슈로 cursor/plugins(미표기)와 AFFiNE(비표준), firecrawl(AGPL)이 카드에 표시됐다.

### X — 이번 주의 인물 중심 화제

11-24 판은 황의 복귀에 대한 업계 반응, 11-25 판은 530A 계좌 소식이었고 11-26 판은 OpenAI 'Private Inference' 알파 시작, 11-27 판은 머스크의 SpaceX 주식 기부 선언과 르쿤의 FSD Level 2 지적이 있었다. X 판은 단일 게시글에 기반하므로 사실 판정이 아니라 발언의 기록이다.

## 비평 — 이번 주 아카이브의 조건들

### 2차 요약에 기댄 주였다

정책 항목(Google 부록, OpenRouter, Signal)의 상당수는 Real Python·Bright Coast 같은 2차 요약을 거쳐 들어왔다. 이 아카이브는 날짜와 수치를 그대로 옮기되 원문 미확인을 항목마다 표기했다. 이 표기는 형식이 아니라 정보다. 2027-02-01 같은 날짜는 원문 약관으로 확인하기 전까지 잠정 값이다.

### 신뢰도가 낮은 항목은 본문에 들이지 않았다

llmnet의 중간·낮음 신뢰도 항목(Antigravity 쿼터, GPT-Live-1.1 음성 벤치 등)은 토요일 판에서도 '참고 보충'으로 분리했다. 반복 노출은 신뢰도를 높이지 않는다.

### 사건과 반응은 한 줄에 놓지 않는다

엔비디아의 등급 전망 하향과 출하 중단은 같은 주 같은 종목에서 나왔지만 인과를 보도로 확인할 수 없다. 주간 리뷰가 나열하는 순서는 시간순이지 인과순이 아니다.
