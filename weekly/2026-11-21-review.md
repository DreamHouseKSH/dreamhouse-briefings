# 주간 정리 — 2026-11-21

> 대상은 2026-11-16(월)~11-20(금)의 한국시간 뉴스·GitHub 아카이브이며, 실제 작성·게시일은 11월 21일입니다. 뉴스 25파일·80항목(IT·AI·모델·엔진 20파일·60항목, X 5파일·20항목), GitHub 5파일·17카드(고유 저장소 16개)를 읽었습니다. 이번 주는 닷새 모두 전 분야 파일이 있으며, 지난주와 달리 결손일이 없습니다. 각 항목의 시간 판정은 일별 파일에 남아 있습니다. 이 글은 월~금 아카이브의 재구성이며 전수 조사가 아니고, 핵심 주장·일정은 공식 원문으로 재확인했지만 회사 주장, 편집 해석, 실제 시험 미수행을 구분했습니다. 11월 20일 금요일 미국 장 마감(한국시간 21일 새벽) 이후의 사건은 이 리뷰의 범위 밖이며 11-21 일별 판에서 다룹니다. 기사 전문·투자 권유는 아닙니다.

## 이번 주 흐름

### 상장은 완주했고, 시장은 다음 질문을 냈다

이번 주의 중심 사건은 앤트로픽의 IPO 완주다. 월요일에는 [주문 수요가 SpaceX의 7배에 달한다는 보도](https://thenextweb.com/news/anthropic-ipo-orders-seven-times-spacex-pricing-week)와 함께 북클로징이 임박했고, 화요일에는 [공모가 상향 전망](https://www.cnbc.com/2026/11/17/anthropic-ipo-price.html)이, 수요일에는 [공모가 83달러 확정](https://www.cnbc.com/2026/11/18/anthropic-ipo-ai-offering-price.html)이 차례로 확인됐다. 목요일 'ANT'는 시초가 111.50달러(+34%)에서 출발해 97.17달러(+17%)로 첫날을 마쳤고([AP](https://apnews.com/article/anthropic-ipo-nasdaq-ai-b6a74b8949021207dc162fcc876c4649)), 역대 최대 조달 기록이 완성됐다.

그런데 같은 목요일 나스닥은 -2.3%였고 알파벳(-3%)·아마존(-3.9%) 등 앤트로픽의 주주들마저 내렸다([BBC](https://www.bbc.com/news/articles/c3x29ggenz12o)). 기존 주도주를 팔아 신규 상장주를 사는 수급 교통정리라는 해석과, AI 투자 급증에 대한 거품 논쟁이 함께 실렸다. 상장이라는 이벤트 자체는 성공이었고, 상장이 드러낸 시장의 체력은 별개의 문제로 남았다. 이 대비는 금요일 미국 장(이 리뷰 범위 밖)에서 더 선명해졌다.

### 좋은 숫자가 주가를 지키지 못한 주

엔비디아는 젠슨 황 없는 첫 실적에서 매출 1,158억 달러(+103%)와 가이던스 상회를 냈고([Yahoo Finance](https://finance.yahoo.com/markets/stocks/articles/nvidia-revenue-doubles-115-8-213800805.html)), 그리고 주가는 실적 서프라이즈에도 2.89% 추가 하락했다([CNBC](https://www.cnbc.com/2026/11/18/nvidia-stock-earnings.html)). 이사회는 같은 주 "젠슨 황의 복귀는 없다"고 선을 그었다. 월요일의 '복귀 추진' 보도([Yahoo/FT 인용](https://tech.yahoo.com/general/breaking-news/article/jensen-huang-weighs-comeback-as-nvidia-ceo-as-allies-lobby-board-ft-reports-bessent-calls-for-dramatic-shak))부터 이사회 확답까지의 일주일이 하나의 호흡으로 읽힌다.

코스피는 더 날카로운 곡선을 그렸다. 17일 5,000이 붕괴하고 SK하이닉스가 7개월 만에 110만원선을 내줬으며 외국인이 1.4조 원을 팔았고([연합뉴스](https://www.yna.co.kr/view/AKR20261117037851008)), 18일 수출 1조 달러 돌파와 한한령 완화 기대에 5,067로 하루 만에 탈환했고, 19일 5,137.89(+1.39%)로 이틀째 올랐다([연합뉴스](https://www.yna.co.kr/view/AKR20261118143200008)). 회복의 재료(수출 대기록·문화교류 합의)와 하락의 재료(외국인 매도·AI 밸류에이션 우려)가 격일로 바뀐 주였다. 그리고 이 회복이 얼마나 갔는지는 금요일의 일별 판이 기록한다.

## 분야별 정리

### IT — 기록의 주, 그리고 기록의 반응

상장과 실적이라는 두 기록 사이에서, 마이크로소프트는 Ignite 2026(11/17~20)으로 방향을 제시했다. 나델라는 ["Copilot은 일의 새 OS"](https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem/)라며 '프론티어 생태계'를 선언했고, Copilot Home·Office in Copilot 정식 출시, 자율 에이전트 Autopilot, Agent 365 Business Analytics·Perception이 나왔다. 후반에는 Copilot Workspaces·Today 모드로 '개인용 에이전트를 회사 전체 에이전트로' 확장하는 그림이 완성됐고([TechSpot](https://www.techspot.com/news/114611-microsoft-thinks-can-make-agentic-ai-work-whole.html)), Azure 쪽에서는 Cobalt 200 GA·Azure Catalyst·Foundry-AKS 연결, NVIDIA와의 Vera Rubin NVL72 가동이 이어졌다([CIO Dive](https://www.ciodive.com/news/microsoft-expands-azure-arsenal-ignite/875125/)).

국내에서는 삼성전자 3분기 보고서의 변화가 눈에 띄었다. 주요 매출처에 아마존이 합류하며 5대 매출처 비중이 14%에서 24%로 올랐다([조선일보](https://www.chosun.com/economy/tech_it/2026/11/16/TOKMXNFTTNAUPN2KG26HMAWGW4/)). 애플의 AI 안경 추진 보도는 삼성·메타와의 '삼파전' 구도를 예고했다. 한편 마이크로소프트의 글로벌 장애(월요일 복구 완료)는 원인이 '네트워크 용량 업그레이드'로 확인됐다([AP](https://apnews.com/article/microsoft-outage-outlook-email-365-recover-ca395c0f1e51af784b6d70afb6554f6a)). **예상 쟁점:** Ignite에서 나온 에이전트 기능들의 제공 단계(정식·미리보기·예고)가 실제 테넌트에서 어떻게 열리는지, 그리고 앤트로픽 첫 분기 실적이 IPO 밸류에이션의 근거를 확인할지가 다음 확인점이다.

### AI — 유통과 접근이 재편된 주

제품 제공의 경계가 여러 갈래로 다시 그어졌다. 앤트로픽은 유료 플랜의 기본 모델을 Opus 5.5로 전환하며 "이제 'think hard'는 빼라"고 안내했고([Claude 문서](https://claude.com/resources/articles/using-claude-opus-5-5-as-you)), Claude는 Canvas 안에서 HTML 인터랙티브 사이트를 만드는 'HTML-in-Canvas'를 열었다([The Decoder](https://the-decoder.com/claude-now-builds-interactive-websites-inside-canvas-graphics-reviving-the-flash-era-with-real-html/)). 목요일에는 Claude Code의 실험적 'Code Mode'(도구 호출을 스크립트로 묶는 방식)와 Perplexity의 'Orchestrator API'(수십 개 모델의 자동 라우팅)가 나란히 나왔다.

자본과 인재의 이동도 있었다. 스탠퍼드 AI 교수진의 Noeri가 1억1,000만 달러로 출범했고([Business Wire](https://www.businesswire.com/news/home/20261116056631/en/)), xAI는 Grok Imagine 인력 약 60명을 정리해고하며 AI 코딩·에이전트로 자원을 옮겼다([TechStartups](https://techstartups.com/2026/11/13/spacex-lays-off-60-grok-imagine-employees-as-elon-musk-shifts-focus-to-ai-coding-and-agents/)). 상장 당일에는 미 하원에 초당파 'AI 안전·혁신 코커스'가 결성됐다. 돈이 프런티어 모델 회사와 정책 채널 양쪽으로 두껍게 붙는 모양이다. **예상 쟁점:** Orchestrator형 라우팅과 Code Mode형 실행 최적화가 표준 API가 될지, 그리고 IPO 이후 앤트로픽의 공시가 경쟁사들의 정보 비대칭을 얼마나 줄일지다.

### 모델 — 프런티어의 가격표가 다시 쓰인 주

이번 주 모델 판의 주제어는 가격이다. OpenAI는 GPT-6.2 Astra·Sol을 내며 Astra 가격을 20% 내렸고 Bedrock 당일 제공을 붙였다([The Verge](https://www.theverge.com/tech/1035483/openai-releases-its-updated-gpt-6-2-astra-model)). 마이크로소프트는 MAI 모델 7종과 함께 플래그십 코딩 모델 MAI-Code-2를 입력 $1·출력 $5로 공개하며 "GPT-6.1의 절반"을 전면에 내세웠다([TechTarget](https://www.techtarget.com/news/microsoft-unveils-ai-models-to-compete-on-cost-and-performance/875045/)). 구글은 Gemini 4 Neon을 입력 $3·출력 $15로 공개해 "프런티어급 지능+빠른 완결"의 균형점을 제시했고([구글 공식 블로그](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)), 알리바바 Qwen4-Max는 작업당 비용 62% 절감을 주장했으나 벤치마크는 들쭉날쭉했다([VentureBeat](https://venturebeat.com/technology/alibabas-qwen4-max-cuts-ai-task-costs-but-benchmarks-show-an-uneven-challenge-to-frontier-rivals)).

오픈 가중치 축에서는 텐센트 Hy4 flash(224B, 활성 12B)가 공개와 동시에 llama.cpp 지원 PR을 받았고([AiBase](https://news.aibase.com/daily/32384)), 구글 Genie 4가 Project Genie에 투입되며 실시간 편집 월드 모델의 문을 열었다([구글 공식 블로그](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/)). 월요일의 GPT-6.1 Terra(컴퓨터 사용 특화, 전작의 절반 가격)와 Runway Praxis-1(로봇 제어, Apache 2.0)까지 포함하면, 이번 주 신모델 전원이 '특화 + 가격'의 조합으로 포지셔닝했다. 범용 최강 하나의 서사는 이번 주에도 없었다.

### 엔진 — 큰 정리와 조용한 하드닝의 주

vLLM v0.34.0은 1,061개 커밋을 실은 대형 릴리스였다. Model Runner V1을 제거하고 기본값을 대폭 바꾼 '정리의 릴리스'로, 이전 버전 사용자는 기본값 변경 목록부터 확인해야 한다([vLLM 릴리스](https://github.com/vllm-project/vllm/releases)). 금요일에는 AMD FlyDSL의 'MonoKernel'로 디코드 지연을 줄이는 실험을 공식 블로그에 실었다([vLLM 블로그](https://vllm.ai/blog/2026-11-18-flydsl-monokernels)).

llama.cpp는 v1.0.0 이후 롤링 머지 체제에서 TTS 3종(Kokoro-82M 내장·tiny-voca·Qwen3-TTS 레퍼런스 모드), M5 텐서 코어 CONV_2D(최대 17.8배), 로더 보안 하드닝, 웹 UI 초기 로딩 63% 절감을 이어갔고, npm 한 줄로 웹 UI를 띄우는 Llama Chat 패키지도 나왔다. 월요일의 SGLang '조용한 오답' 수정(같은 모델이 GSM8K 50.87% vs 93.48%)은 이번 주 가장 무서운 항목이다: 엔진 버그가 느려지는 게 아니라 틀리게 만드는 사례다. NVIDIA는 RTX Spark 데스크톱(ASUS·Dell·MSI)을 출시하며 "120B 모델 로컬 실행"을 하드웨어 카탈로그로 옮겼다.

### GitHub — 스킬 감사와 에이전트 인프라의 주

이번 주 GitHub 판은 닷새 모두 발행됐고 17개 카드, 중복을 빼면 16개 저장소다. 흐름은 세 갈래다. ① 스킬·지침 부류: superpowers(방법론), last30days-skill(검색), stitch-skills, ffmpeg-skill, NVIDIA/SkillEvaluator(스킬 평가, 두 번 선정). 지침을 '심는' 도구에서 지침을 '검증하는' 도구까지 같은 주에 나왔다. ② 에이전트 인프라: agent UI 프로토콜(ag-ui), 소프트웨어→CLI 변환(CLI-Anything), 웹 데이터 파이프(firecrawl). ③ 실용 유틸리티: 앱스토어 규정 도우미, 모델 교육 재현(minimind), openvino.

주 후반의 특이점은 목록의 급변동이다. 11-19와 11-20 사이 목록의 절반 이상이 갈렸는데, 이 아카이브의 규칙대로 이것은 인기의 소멸이 아니라 GitHub 이동 관측 기간의 갱신으로 읽는다. NVIDIA/SkillEvaluator의 반복 선정이 보여주듯, 스킬 생태계가 만들기에서 감사하기로 넘어가는 조짐이 이번 주 판의 가장 흥미로운 신호다.

## 비평 — 이번 주 아카이브의 조건들

### 결손은 없었지만 경계는 있었다

닷새 전 분야 발행은 지난주(결손 3일)와 대비되는 기록이다. 다만 경계 표기는 계속됐다. 공모가 상향 전망(화)·코커스 결성(목) 같은 항목은 보도 시각 기준의 구간 판정이 필요했고, 일요일 심야에 확인된 월요일 아침 판의 몇몇 항목은 '구간 경계'로 분리됐다. 이 리뷰는 그 분리를 유지한다. 경계 항목을 구간 내 확정 건수로 다시 세면 수집 구간의 의미가 사라진다.

### '최대'와 '최초'는 조건을 달고 온다

역대 최대 IPO는 조달액 기준이고, 매출 두 배는 전년 동기 대비이며, 62% 비용 절감은 자사 측정 태스크 기준이다. 17배라는 RTX Spark의 메모리 대역폭 주장도 특정 조건의 수치다. 이 표현들이 틀렸다는 뜻이 아니다. 다음 주에 다시 확인할 숫자가 무엇인지를 구분하자는 뜻이다.

### 금요일 밤은 이 리뷰 밖이다

이 리뷰가 닫히는 시점(금요일 한국 장 마감)과 다음 아카이브가 여는 시점(금요일 미국 장) 사이에 시장은 다시 크게 움직였다. 주간 리뷰의 경계가 사건의 경계와 일치하지 않는다는 것이 주간 단위 읽기의 구조적 한계다. 이 구간의 사건은 11-21 일별 판을 참조하라.
