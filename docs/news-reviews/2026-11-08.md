## X 후보와 확인 한계

기존 추적 명단의 인물을 대상으로 아래 검색을 했다. 날짜가 새로운 집계 페이지에 오래된 게시글이 실려 있는 경우를 구분했다. Sam Altman의 인간 통제·RAM 관련 결과는 11/3~4 게시글을 다시 다룬 것으로 보여 이번 구간의 새 글로 채택하지 않았다. Musk 관련 결과에는 암호자산 가짜 인용 부인 등 후보가 있었지만, 이번 조사에서 원문 게시글과 반응을 직접 검증하지 못해 인용 기사로 만들지 않았다. 다른 인물의 제품·전략 주장은 집계 페이지의 설명만으로 확정하지 않았다.

11/8은 일요일이라 정규 GitHub 트렌드 발행일이 아니다. 이 뉴스판은 GitHub 아카이브와 독립적으로 검사·발행한다. 현재 접근 가능한 저장소·릴리스 API를 GitHub Trending의 당시 순위나 일간 증가량으로 대체하지 않았다. 같은 날짜 GitHub 아카이브가 없으므로 통합 모션그래픽·음성 발표를 생성했다고 표시하지 않는다.
