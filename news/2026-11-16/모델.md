## 1. OpenAI 'GPT-6.1 Terra' 공개 — 컴퓨터 사용 특화 중형 모델, API 가격은 전작의 절반

- **원문:** https://openai.com/index/introducing-gpt-6-1-terra/
- **분야:** AI 모델
- **최초 게시:** OpenAI 공식 페이지(시각 미표시), 관련 보도 2026-11-14~15
- **시간 판정:** 정규 구간 내 확인(정확한 공개 시각 미확인)

### 요약

OpenAI가 컴퓨터 사용(computer use, AI가 화면을 보고 앱을 직접 조작하는 능력)과 시각 추론에 특화된 중형 모델 GPT-6.1 Terra를 공개했다. 제안서 작성, 기술 도면 해석, 폼 입력, 영상 편집처럼 "하루 업무를 채우는 컴퓨터 기반 작업"을 겨냥한다. 표준 API 가격은 입력 100만 토큰당 1달러(캐시 입력 0.05달러), 출력 100만 토큰당 5달러로 GPT-5.6 Terra와 GPT-6.1 Sol 대비 50% 낮다. Plus·Pro·Enterprise·Edu 사용자의 ChatGPT Work와 Codex, 그리고 API(`gpt-6.1-terra`)로 제공된다.

성능 수치(OpenAI 자체 측정)는 이렇다. 전문가 작업 벤치마크 'Agents' Last Exam'에서 미디엄 리즈닝 기준 GPT-5.6 Terra보다 15포인트 높고 비용은 약 3분의 1이며, 최상위 모델 GPT-6 Astra와 대등한 성적을 토큰당 10분의 1 가격에 낸다. 최대 노력 설정에서는 Claude Opus 5.5보다 토큰 효율이 3배 이상 좋고 토큰 가격은 4분의 1로, 작업당 비용이 약 9분의 1이라고 주장한다. 환각·사실 오류는 내부 오류 유도 벤치마크에서 저노력 설정 기준 53.6%에서 16.7%로, 최대 노력 기준 4.3%로 낮아졌다. 코딩 벤치마크 Terminal-Bench 4.0에서는 최대 노력 기준 50.3%로 GPT-5.6 Terra(21.5%)의 두 배 이상이고, Terminal-Bench-Science 0.1에서는 GPT-6.1 Sol을 넘어서며 Opus 5.5와 5점 차까지 따라붙었다(비용은 5분의 1 미만 추정). 다만 가장 복잡한 코딩 작업은 GPT-6.1 Sol과 GPT-6 Astra가 낫다고 OpenAI는 인정했다. 안전 등급은 자체 대비 프레임워크(Preparedness Framework)에서 사이버보안 'Critical' 문턱에 해당하며 프롬프트 인젝션 저항성이 개선됐다고 밝혔다.

### 논조·다른 시각

- **기사 논조:** 해당 없음 — 제조사 공식 발표다.
- **논조 점검:** 성능·비용 비교는 모두 OpenAI 자체 평가다. '작업당 비용 9분의 1' 같은 수치는 OpenAI의 추정 시나리오 기준이며, 사용한 벤치마크(Agents' Last Exam, OSWorld 2.1 등)의 대표성 논란 여지가 있다. 공식 페이지에 공개 시각이 표시돼 있지 않아 정확한 출시 시점은 보도 시점으로 짐작할 뿐이다.
- **다른 시각:** 앤트로픽의 IPO 주간에 Opus 5.5를 직접 겨냥한 가격·비용 비교를 내놓은 정면 공세다. '토큰 가격'이 아니라 '작업당 비용' 프레임으로 승부하려는 전략으로 읽힌다.

**시사점:** 대량 자동화(송장 처리 같은)를 노린 중형 모델의 가격 인하가 에이전트 도입의 총비용 계산을 다시 하게 만든다. 개발자는 Terra급 중형과 Sol·Astra급 상위 모델 사이의 라우팅(작업별 모델 배정) 설계가 더 중요해진다.

## 2. Runway, 로봇 제어 모델 'Praxis-1' 오픈 가중치 공개 — Apache 2.0으로 상업적 사용 가능

- **원문:** https://deai.org/news/runway-praxis-1-open-weights-robot-control
- **분야:** AI 모델 · 로봇
- **최초 게시:** deai.org 2026-11-15
- **시간 판정:** 정규 구간 내 확인

### 요약

영상 생성 AI 기업 Runway가 로봇 제어용 27B MoE 월드 액션 모델(world action model, 환경을 예측하고 다음 동작을 생성하는 로봇용 모델) Praxis-1을 오픈 가중치로 공개했다. Apache 2.0 라이선스로 상업적 사용이 가능하다. 로봇 벤치마크 RoboLab-120에서 46.2%(자체 보고)를 기록했고, 로봇 전문지 The Robot Report의 리더보드 기준 전체 5위권이다. 가중치는 bf16 기준 54.4GB, 17개 샤드로 배포되며 15Hz 추론과 24스텝 액션 청크를 지원한다. LeRobot과 vLLM-Omni를 지원하고 H100부터 RTX 5090, Jetson Thor까지 배포 폭이 넓다. 로봇 기업 노블 머신스는 자체 시험에서 15개 과제를 모두 통과했다고 밝혔다(제조사 주장).

### 논조·다른 시각

- **기사 논조:** 긍정 — 오픈 공개 중심의 보도다.
- **논조 점검:** RoboLab-120 46.2%와 노블 머신스의 시험 결과는 모두 자체 보고이며 독립 검증 전이다. 11-15 판 AI 2번의 Gemini Robotics 5.0.1(58.4%, Google 자체 측정)처럼 이 분야의 벤치마크 수치는 과장 논란이 반복되고 있다.
- **다른 시각:** 11-15 판의 OpenAI 로봇 브레인 프로젝트 보도와 같은 '로봇 제어 범용화' 흐름에서 오픈 진영이 내놓은 대응이다. 다만 xAI의 GR-5.0 예측치(70.3%)에는 크게 미달한다.

**시사점:** VLA(비전-언어-액션)급 로봇 제어 모델이 상업적 사용이 가능한 라이선스로 풀리면서 로봇 스타트업과 연구실의 진입 비용이 낮아진다. 실기 검증 결과가 나오기 전까지는 '가능성' 단계로 봐야 한다.

## 3. [후속] LongCat-2.5, 학습 전 과정 '비엔비디아' 확인 — 화웨이 Ascend 194장으로 배포 시연

- **원문:** https://the-decoder.com/meituan-releases-a-1-6-trillion-parameter-agent-model-that-never-touched-an-nvidia-gpu/
- **분야:** AI 모델 · 인프라
- **최초 게시:** The Decoder 2026-11-15
- **시간 판정:** 정규 구간 내 확인 (11-15 판 1번 후속)

### 요약

어제(11-15 판) 전한 메이투안의 1.6조 파라미터 에이전트 모델 LongCat-2.5가 학습 전 과정에서 엔비디아 GPU를 한 번도 쓰지 않고 중국산 하드웨어로만 학습된 것으로 확인됐다(The Decoder). 화웨이 Ascend Atlas A2 클러스터 194장으로 샘플 배포를 시연했고, 4비트 양자화(가중치의 표현 정밀도를 낮춰 메모리와 연산을 줄이는 기법)로 처리량을 43% 끌어올렸다. 개발 과정에서 엔비디아의 가이던스도 받지 않았다고 한다. 에이전트 벤치마크 Terminal Bench v2.1에서는 88.4점으로 Claude Opus 5(89.1)와 DeepSeek-V4.1-Flash(90.6)에 근소하게 뒤진다.

### 논조·다른 시각

- **기사 논조:** 중립 — 사실 확인 중심이다.
- **논조 점검:** 194장은 '샘플 배포' 시연 규모이며 전체 학습 클러스터 규모와 학습 비용·기간은 비공개다. 벤치마크 격차는 작지만 단일 벤치마크 기준이다.
- **다른 시각:** 미국 수출 규제 아래서 중국의 'AI 자급 스택(비엔비디아 학습-배포 체인)'이 수치로 드러난 사례다. 엔비디아의 거버넌스 공백(오늘 IT 1번)과 겹쳐 시장 심리에 영향을 줄 수 있다는 관측이 나온다.

**시사점:** 중형급 이상 성능의 모델이 비엔비디아 스택에서 학습·배포될 수 있음을 보여준다. Ascend 생태계의 소프트웨어 성숙도(컴파일러·양자화 도구)가 앞으로의 관전 포인트다.
