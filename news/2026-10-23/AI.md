## 1. OpenAI Decisions API 정식 출시, 반복 판단을 전용 경로로 분리

- **원문:** https://openai.com/index/decisions-api/
- **분야:** AI · 개발 플랫폼
- **날짜:** 2026-10-22 (원문 날짜, 세부 시각 미표기)

### 요약

OpenAI가 Decisions API(Application Programming Interface, 프로그램끼리 기능을 주고받는 창구)를 정식 출시했다. 긴 답변 생성보다 입력 분류, 요청 전달 경로 선택, 다음 행동 결정처럼 답의 범위가 정해진 작업에 초점을 둔 서비스다. 기반 모델은 GPT-6 Luna이며 텍스트·이미지·구조화된 데이터를 받는다.

개발자는 질문과 허용할 답을 지정하고, 결과를 확률·선택지·점수 중 하나로 받는다. 공개 시험판 이후 실시간 음성 서비스 GPT-Live 연동, 반복 문맥을 재사용하는 프롬프트 캐시(prompt cache, 이미 처리한 입력을 재사용하는 저장 기능), 미국·유럽 내 추론 처리 기능이 추가됐다. 한 요청의 질문 한도는 400개로 늘었다.

OpenAI 발표 기준 같은 Luna를 Responses API로 호출할 때보다 최대 10배 빠르다. 기본 입력 가격은 100만 토큰당 0.10달러, 캐시된 입력은 0.01달러이며 출력 토큰 요금은 없다. 다만 회사가 제시한 속도와 고객 사례는 모든 업무에서 동일하게 재현된다는 뜻은 아니다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 낮은 지연과 비용을 강조한 공급자 발표다.
- **논조 점검:** 최대 속도와 고객별 측정치는 조건이 다르다. 일반 응답 생성 서비스를 완전히 대체한다는 설명은 아니다.
- **다른 시각:** 찾은 반론 없음 (검색 범위: Decisions API 2026-10-22 출시 관련 검색과 [공식 개발 가이드](https://developers.openai.com/api/docs/guides/decisions)).
  - 예상 쟁점: 빠른 선택과 올바른 선택은 별개이므로 실제 입력으로 오류율과 사람에게 넘길 조건을 평가해야 한다.

**시사점:** 에이전트 전체를 한 모델 호출에 맡기기보다 자주 반복되는 제한된 판단을 분리하는 설계가 구체화됐다.

## 2. Uber, ChatGPT Work를 3만 명 이상 직원에게 확대

- **원문:** https://openai.com/index/uber-chatgpt-work-rollout/
- **분야:** AI · 기업 도입
- **날짜:** 2026-10-22 (원문 날짜, 세부 시각 미표기)

### 요약

Uber가 ChatGPT Enterprise 안의 업무 에이전트인 ChatGPT Work를 전사에 배포한다고 발표했다. OpenAI가 공개한 대상은 전 세계 직원 3만 명 이상이며, 앞선 1,000명 규모의 시험 운영에서 범위를 확대한 것이다. 발표의 대상은 직원 업무이고 운전자 전체에게 제공한다는 내용은 아니다.

서비스는 Google Drive·Gmail·Google Calendar·Slack 같은 업무 도구와 연결해 자료 조사, 회의 준비, 발표 자료 작성, 데이터 분석과 여러 앱에 걸친 작업을 지원한다. GPT-6.1 Sol이 기본 모델로 배치되며 음성·이미지 기능도 활용한다. 개발 조직은 Codex 사용을 이어간다.

확대 적용에는 Uber 내부의 AI 활용 지침 모음, 승인된 연동과 직원 교육이 함께 포함된다. 양사는 도입이 진행되면서 실제 활용과 측정 가능한 성과를 추가로 공개하겠다고 밝혔다. 따라서 현재 공개된 인원 수는 제공 범위이지, 정기 사용자 수나 생산성 향상 실적은 아니다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 공급자와 고객 경영진의 기대를 중심으로 구성돼 있다.
- **논조 점검:** 이용률·절감 시간·비용 대비 효과는 아직 공개되지 않았다.
- **다른 시각:** 찾은 반론 없음 (검색 범위: Uber ChatGPT Work 10월 22일 발표 관련 자료). 같은 발표의 재보도는 별도 반론으로 취급하지 않았다.
  - 예상 쟁점: 도구별 접근 통제와 결과 검토 체계가 전사 확대의 실제 효율을 좌우할 수 있다.

**시사점:** 배포 인원보다 승인된 연결 범위, 직원 교육, 실제 완료 업무의 품질을 함께 확인해야 하는 도입 사례다.
