## 1. Ollama 사전판, Apple용 MLX 모델의 여러 요청 동시 생성 지원

- **원문:** https://github.com/ollama/ollama/releases/tag/v0.40.17-rc0
- **분야:** 엔진
- **최초 게시:** GitHub published_at 2026-11-10 22:25:00 UTC → 2026-11-11 07:25:00 KST
- **시간 판정:** 정규 구간 내 확인

### 요약

Ollama v0.40.17-rc0에는 Apple용 기계학습 프레임워크 MLX를 사용하는 모델이 여러 생성 요청을 함께 처리하는 변경이 포함됐다. 기본 동시 요청 수는 여전히 하나이며, OLLAMA_NUM_PARALLEL 설정으로 늘릴 수 있다. 

기다리던 두 번째 사용자가 앞선 요청이 완전히 끝나기 전부터 답변을 받게 하는 것이 핵심이다. 각 요청의 상태와 응답 흐름은 따로 유지한다. ([개발 설명](https://github.com/ollama/ollama/pull/19197))

동시 실행이 모든 성능 지표를 개선하는 것은 아니다. 개발자가 Apple M5 Max에서 수행한 비교에서 Gemma 4 12B의 두 번째 요청이 첫 글자를 받기까지는 7.45초에서 4.69초로 줄었지만, 두 요청이 모두 끝날 때까지는 9.57초에서 10.19초로 늘었다. Qwen 3.8 27B도 비슷한 교환관계가 있었다. 개발팀의 특정 설정 측정이며 독립 검증이나 모든 하드웨어의 보장 수치가 아니다. 동시 요청마다 메모리가 필요하고, 여러 요청을 함께 생성할 때는 추측 디코딩을 잠시 멈추는 제약도 명시됐다.

### 논조·다른 시각

- **기사 논조:** 혼재 — 대기 사용자 응답은 빨라질 수 있지만 총 처리시간과 메모리 비용이 남는다.
- **논조 점검:** 정식판이 아닌 릴리스 후보이며, 개발자 자체 시험을 보편적인 속도 향상으로 포장하지 않는다.
- **다른 시각:** 독립 반론은 확보하지 못했다(공식 릴리스·변경 요청 검토). 개발자 자신이 단독 요청의 자원 독점이 줄고, 요청별 캐시가 유휴 메모리를 유지하는 비용을 설명했다. ([제약과 측정 표](https://github.com/ollama/ollama/pull/19197))

**시사점:** 여러 사람이 같은 로컬 모델을 쓰는 경우 대기 경험을 개선할 후보지만, 운영 적용 전 자신의 모델·메모리·동시 사용자 수로 확인해야 한다.

## 2. llama.cpp, Kimi K3.1의 이미지 입력 경로를 사전판에 추가

- **원문:** https://github.com/ggml-org/llama.cpp/releases/tag/b12259
- **분야:** 엔진
- **최초 게시:** GitHub published_at 2026-11-10 22:11:56 UTC → 2026-11-11 07:11:56 KST
- **시간 판정:** 정규 구간 내 확인

### 요약

llama.cpp b12259에는 Kimi K3.1의 이미지 처리 지원이 추가됐다. 11월 8일 브리핑에서 다룬 텍스트 실행 지원에 이어, 모델이 이미지를 입력받는 경로가 새로 반영된 것이다. 

변경 기록에는 K2.5·K3.1의 이미지 전처리와 영상 특징을 언어 모델 쪽으로 전달하는 연결 부분을 수정한 내용도 포함돼 있다. ([변경 요청](https://github.com/ggml-org/llama.cpp/pull/31980))

지원 범위를 과장하지 않는 것이 중요하다. 개발자는 텍스트 모델의 일부와 이미지 처리 모듈의 전체 가중치로 시험했다고 설명했다. 완전한 모델 전체를 모든 기기에서 검증했다는 뜻은 아니다. b12259도 GitHub에서 사전판으로 표시된다. 따라서 이번 소식은 Kimi 새 모델 자체의 출시가 아니라 기존 모델을 실행하는 오픈소스 엔진의 입력 방식 확대다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 로컬 실행 시 선택할 수 있는 입력 경로가 늘었다.
- **논조 점검:** 기능 반영과 전체 모델·하드웨어의 안정성 검증은 다르다. 이 브리핑에서는 설치나 성능 재현 시험을 하지 않았다.
- **다른 시각:** 찾은 독립 반론 없음(검색 범위: 공식 릴리스·연결된 변경 요청). 변경 요청이 밝힌 제한된 시험 범위를 그대로 남겼다.

**시사점:** 기존 텍스트용 설정을 그대로 이미지 지원의 증거로 삼지 말고, 변환된 모델과 이미지 처리 파일, 사용 엔진 버전을 함께 확인해야 한다.
