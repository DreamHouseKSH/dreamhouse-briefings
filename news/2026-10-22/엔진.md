## 1. Ollama v0.40.8, Recursive Flint 지원 — 이번 지원 범위는 macOS

- **원문:** https://github.com/ollama/ollama/releases/tag/v0.40.8

- **날짜:** 2026-10-22 01:20:30 KST (GitHub 공개 시각 2026-10-21 16:20:30 UTC)

### 요약

Ollama가 정식 릴리스 v0.40.8에서 Recursive의 코딩 모델 Flint 지원을 추가했다. 낯선 저장소 이해, 버그 추적, 기능 구현과 테스트 작성처럼 여러 파일·도구를 오가는 작업을 대상으로 소개했다. 컨텍스트는 262K 토큰(모델이 한 번에 참고하는 입력 단위)으로 표기됐다.

Flint는 전체 400억 매개변수 중 토큰당 약 25억을 사용하는 MoE(Mixture of Experts, 일부 하위 네트워크를 골라 계산하는 전문가 혼합) 모델이며 Apache 2.0 라이선스다. 활성 매개변수가 적다는 설명을 모델 전체의 메모리 요구량이 작다는 뜻으로 읽어서는 안 된다.

가장 중요한 제한은 이번 Flint 지원이 macOS에 한정된다는 점이다. 다른 GPU(Graphics Processing Unit, 병렬 연산 장치) 지원은 후속 릴리스로 예고됐다. 이는 Ollama 전체가 macOS 전용이라는 의미가 아니라, 이 버전에서 새 모델을 실행하는 지원 범위를 설명한다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 새 모델 지원과 코딩 작업 활용을 소개한다.
- **논조 점검:** 릴리스가 인용한 성능 평가는 모델 개발사의 수치다. 이 브리핑은 성능을 독립 재현하지 않았으며 지원 범위만 확인했다.
- **다른 시각:** 찾은 반론 없음 (확인 범위: 공식 릴리스·모델 안내). 예상 쟁점: 최대 컨텍스트를 실제 장비에서 사용하는 데 필요한 메모리와 응답 속도는 별도 검증이 필요하다.

**시사점:** macOS 로컬 코딩 모델의 선택지가 늘었다. 다른 운영체제·연산 장치에서는 이번 지원이 동일하게 제공된다고 가정하지 않아야 한다.
