## 1. Meituan, LongCat-2.5 가중치 MIT로 공개 — 1.6조 파라미터 MoE, 3.56TB 체크포인트

- **원문:** https://huggingface.co/meituan-longcat/LongCat-2.5
- **보도:** https://dataphoenix.info/news/meituan-longcat-2-5-open-weights
- **분야:** 모델 · 오픈 가중치 / 멀티모달 MoE
- **날짜:** Data Phoenix 2026-11-13 보도, 저장소 기록상 가중치 샤드 업로드 11-4~5·모델 카드 갱신 11-9
- **시간 판정:** 구간 경계 — 보도는 직전 판 구간, 저장소·가중치의 실제 첫 공개 시점은 확인되지 않음

### 요약

Meituan이 LongCat-2.5의 가중치를 Hugging Face에 표준 MIT 라이선스로 공개했다. 모델 카드 기준 총 1.6조 파라미터에 토큰당 약 480억 개를 활성화하는 네이티브 멀티모달 MoE(Mixture-of-Experts, 전문가 조합 — 일부 하위 네트워크만 골라 계산하는 구조)다. 저장소에는 3.56TB 체크포인트와 208개의 Safetensors 샤드, 이미지·비디오 토큰 식별자를 포함한 구성 파일이 올라와 있다. 시각 이해와 에이전트 코딩(복잡한 코드베이스 개발, 전체 프로젝트 빌드, 3D 작업)의 결합을 표방한다.

학습 기법으로는 장기 과제 에이전트 강화학습(실제 엔지니어링 작업과 재현 가능한 실패 사례 활용), 다중 교사 학습, 국산 AI 가속기 인프라 최적화를 든다. 모델 카드의 자체 평가는 Terminal Bench v2.1 88.4, DeepSWE v1.1 64.6, Vision2Web 78.6이며, 별표 없는 수치는 사내 측정으로 "참고용"이라고 스스로 표시한다. 라이선스는 Meituan 상표·특허권을 부여하지 않는다는 단서가 붙는다. 최근 다른 대형 오픈 가중치 공개가 상용 모델 서비스(MaaS) 이용을 제한한 것과 달리 표준 MIT를 택한 점이 Data Phoenix가 짚은 차이다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 공개 사실과 자체 수치 중심이다.
- **논조 점검:** 모든 벤치마크가 회사 측 자료이며 독립 재현은 없다. 3.56TB 체크포인트는 개인 장비가 아닌 다중 GPU 환경이 전제다. 최초 공개 시점이 저장소 기록만으로는 확정되지 않는다.
- **다른 시각:** Data Phoenix는 라이선스 대조(직전 주 Inkling 2 Small의 상용 제한)와 공개 시점의 불명확성을 함께 지적했다. 11-13 판의 ERNIE 5.5 Flash(Apache 2.0 예고)와 함께 중국발 대형 모델의 허용 라이선스 흐름으로 읽을 수 있다.

**시사점:** 조 단위 파라미터 오픈 가중치가 표준 MIT로 옮겨가는 흐름의 한 사례다. 실제 채택 판단은 서빙 비용 계산과 독립 벤치마크가 나온 뒤가 맞다.

## 2. [참고 보충] Edge0-145B·120B 공개 — Qwen 파생 압축 MoE와 전문가 스트리밍 엔진의 결합, 단 "아무 노트북이나"는 아니다

- **원문:** https://aibrainworx.com/edge0-145b-120b-qwen-strata-local-models/
- **분야:** 모델 · 오픈 가중치 / 로컬 추론
- **날짜:** 공식 블로그 2026-11-12, 저장소 릴리스 표기 11-13, AiBrainWorX 검증 보도 11-14
- **시간 판정:** 정규 구간 밖 참고 보충 — 공개는 구간 밖, 구간 내 검증 보도 확인

### 요약

AutoArk의 Edge0가 Qwen3.8-Flash-Next 파생의 145B·120B 모델을 Hugging Face에 공개했다. Strata의 포크(fork, 기존 소스를 가져와 따로 발전시키는 방식) 엔진이 전문가 가중치를 저장장치-시스템 메모리-GPU 사이에서 스트리밍하는 방식으로 큰 MoE 모델을 로컬에서 돌리는 설계다.

다만 AiBrainWorX의 확인 결과 실제 동작 조건은 "노트북에서 돌아간다"는 식의 해석과 거리가 있다. 이 두 모델은 Linux·Windows에서 NVIDIA GPU와 CUDA 13이 필요하다고 문서화돼 있고, 검증 보도는 시험된 메모리 예산과 모델 라이선스를 따져봐야 한다고 지적했다. 공식 블로그(11-12)와 저장소 릴리스 표기(11-13)의 날짜도 하루 어긋난다.

### 논조·다른 시각

- **기사 논조:** 검증형 — 홍보 문구보다 동작 조건을 확인한 보도다.
- **논조 점검:** 보도의 성능 도표는 발표사 자체 측정치를 옮긴 것으로 독립 검증이 아니다. 라이선스 전문은 저장소에서 직접 확인해야 한다.
- **다른 시각:** 같은 주 공개된 11-14 판의 ZONOS3-Mini(서브초 지연 오픈 TTS)처럼 '오픈 가중치 + 로컬 실행' 조합이 늘고 있으나, 실제 하드웨어 요구 조건은 모델마다 다르다.

**시사점:** 압축 MoE와 전문가 스트리밍의 결합은 로컬 대형 모델의 한 경로다. 도입 검토는 문서상 지원 환경(GPU 세대·메모리·CUDA 버전)과 라이선스 확인이 먼저다.
