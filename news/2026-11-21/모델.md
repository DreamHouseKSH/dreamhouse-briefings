## 1. NVIDIA, 연속 확산 언어 모델 'Nemotron-Labs-Sigma' 공개 — 3B/8B 14개 체크포인트, 오픈 가중치

- **원문:** https://www.marktechpost.com/2026/11/20/nvidia-nemotron-labs-sigma-continuous-diffusion-language-model/ (MarkTechPost)
- **분야:** 모델 · 오픈 가중치/확산 언어 모델
- **최초 게시:** MarkTechPost 2026-11-20
- **시간 판정:** 정규 구간 내 확인

### 요약

NVIDIA가 Nemotron-Labs-Sigma를 공개했다. 3B와 8B 두 규모에 베이스·인스트럭트·소수 스텝 증류(NFE 2/4/8/16)·셀프 스페큘레이티브까지 14개 체크포인트의 연속 확산(continuous diffusion) 언어 모델 패밀리다. LLaDA·Dream 같은 기존 확산 LLM이 이산 토큰 사이를 뛰는 방식인 데 비해, Sigma는 각 토큰을 학습된 16차원 임베딩 공간의 한 점으로 놓고 가우시안 노이즈를 입혔다 제거하는 방식으로 학습한다. 연속 공간이라 궤적이 매끄러워 적은 스텝에서도 품질이 서서히 떨어지고(graceful degradation) 증류가 효율적이라는 게 연구팀의 주장이다.

구조는 Ministral 스타일 디코더 전용 트랜스포머(GQA·SwiGLU·RoPE)에 약 1조 토큰의 자기회귀 웜스타트 후 0.3조 토큰 확산 학습. 생성은 64토큰 블록 단위로, 블록마다 디노이즈 후 KV 캐시에 확정한다. 문맥은 4,096토큰(8B 인스트럭트는 8,192).

성능(NVIDIA 자체 평가, 6개 태스크 평균): Sigma-8B 베이스가 256 DDPM 스텝에서 71.16으로 NLD-8B(70.22)·Qwen3-8B(68.91, AR)·Dream-7B(58.74)·LLaDA-8B(41.78)보다 높다. 코딩이 강점(HumanEval 65.12 vs NLD-8B 62.80)이고 어려운 추론은 약점(AIME25 17.00)이다. 인스트럭트 10개 태스크 평균은 59.14로 NLD-8B(59.92)에 근소하게 뒤진다.

속도가 실전 포인트다. 8스텝 증류 8B는 평균 70.34로 256스텝 교사 모델에 근접하고, 셀프 스페큘레이티브 체크포인트는 확산 헤드가 32토큰 블록을 초안 잡고 자기 AR 헤드가 검증해 GB200+SGLang 기준 AR 디코딩 대비 평균 3.46배(최대 4.20배) 빠르다. 출력은 그리디 AR과 정확히 일치한다는 설명이다. H100 한 장에서 베이스 모델 기준 120~140토큰/s.

배포는 Hugging Face의 NVIDIA Nemotron Open Model License로 상업적 사용 가능 명시. CUDA GPU(Ampere 이상) bf16 전용, CPU 미지원. vLLM·SGLang·Docker Model Runner 서빙을 안내하고 호스티드 API는 없다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 제품 소개형 리포트다.
- **논조 점검:** 모든 벤치마크는 NVIDIA 자체 평가다. '최초의 대규모 연속 확산 언어 모델 패밀리'라는 표현도 연구팀의 주장이다. 4,096토큰 문맥과 GPU 전용은 2026년 기준으로 좁은 제약이다.
- **다른 시각:** 확산 언어 모델의 가치는 품질 1위가 아니라 '적은 순방향 계산으로 여러 토큰'이라는 속도 축에 있다. Sigma의 셀프 스페큘레이티브가 그 축을 정면으로 겨냥한 설계라는 점에서, AR 모델과의 품질 대결보다 지연·비용 민감 워크로드에서의 실측이 진짜 승부처라는 해석이 있다.

**시사점:** 확산 LLM이 연구 시연(LLaDA·Dream)에서 NVIDIA의 공학 패키지(증류+스페큘레이티브+서빙 안내) 단계로 넘어왔다. 로컬·엣지 추론 생태계(엔진 브리핑 참조)가 이 체크포인트를 얼마나 빨리 흡수하는지가 파급력의 척도다.

## 2. RadixArk, RL-only 에이전틱 코딩 모델 'DaisyRose-27B' 출시 — Terminal Bench 4.1이 5.6→12.0으로

- **원문:** https://www.marktechpost.com/2026/11/20/radixark-daisyrose-27b-agentic-model/ (MarkTechPost)
- **분야:** 모델 · 오픈 가중치/코딩 에이전트
- **최초 게시:** MarkTechPost 2026-11-20
- **시간 판정:** 정규 구간 내 확인

### 요약

RadixArk가 첫 오픈 가중치 모델 DaisyRose-27B를 Apache 2.0으로 내놓았다. Qwen3.8-27B를 아키텍처 변경 없이 강화학습(RL)만으로 포스트트레이닝한 에이전틱 코딩 모델로, SFT나 증류를 거치지 않았다는 점이 실험적 가치다. 학습은 Eigent AI와 함께 큐레이션한 약 1,200개 태스크(수천 후보 중 베이스 모델의 실패 유형별 선정)로 144장의 H200에서 18일, 사고방식은 샌드박스 시도당 최대 1.5시간을 허용했다.

결과(모두 RadixArk 자체 보고): Terminal Bench 4.1 pass@1이 5.6에서 12.0으로 두 배 이상. DeepSWE v1.1 +4.0(46.2), SWE Bench Pro v2 +3.4(94.7), IFBench 82.4로 자사 9개 모델 비교표에서 1위. 반면 HLE(텍스트) 34.3은 베이스 대비 +0.4에 그쳐 지식 과제의 이득은 작다. 큰 MoE 모델과의 비교에서는 MiMo V2.6 Flash(309B)가 Terminal Bench 4.1에서 16.1, Inkling 2 Small(594B)이 DeepSWE 72.1로 앞선다.

배포는 BF16(약 52GB)·FP8(29GB)·NVFP4(23GB, Blackwell 전용)·GGUF. H200·B200·GB300·RTX PRO 6000·RTX 5090·DGX Spark까지 GPU 한 장 목표다. 권장 서빙은 SGLang+Qwen3.8-27B-DSpark 드래프트의 스페큘레이티브 조합이고 vLLM도 지원한다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 출시 리포트다.
- **논조 점검:** 전 수치가 자사 측정이며 DaisyRose 점수는 BF16/FP8 중 높은 쪽을 택했다. RL-only가 만든 이득이 일반화되는지, 특정 벤치마크 분포에 과적합된 것인지는 독립 평가가 가려야 한다. Terminal Bench 4.1의 절대 점수(12.0)가 낮다는 것 자체가 이 벤치마크의 난도를 보여준다.
- **다른 시각:** 'SFT 없이 RL만'은 DeepSeek 계열 실험 이후 반복되는 검증 라인이다. 27B 단일 GPU급에서 이 레시피가 재현됐다는 것은 중소 조직의 에이전트 포스트트레이닝 비용 가정을 다시 쓰게 만드는 자료다. 반대로 18일×144 H200은 중소 조직이 감당할 규모가 아니라는 반론도 성립한다.

**시사점:** 이번 주 MAI-Code-2(가격), Gemini 4 Neon(균형)에 이어 오픈 가중치 코딩 축의 세 번째 선택지다. 라이선스(Apache 2.0)와 단일 GPU 배포가 명확해, 사내 코드에 상용 API를 못 붙이는 조직의 시험 대상이 될 조건을 갖췄다.

## 3. [후속] 텐센트, 플래그십 Hy4(770B)까지 완전 오픈소스 — Hunyuan 시리즈 전면 개방 완료

- **원문:** https://freellm.vip/news/tencent-hunyuan-open-sources-hy4-and-hy4-flash-770b-and-224b-moe-models-with-1m-context-and-native-multimodal-support (FreeLLM, 텐센트 혼위안 발표 인용) · 가중치: https://huggingface.co/tencent/Hy4 · https://huggingface.co/tencent/Hy4-flash
- **분야:** 모델 · 오픈 가중치/중국
- **최초 게시:** FreeLLM 2026-11-20 17:53
- **시간 판정:** 정규 구간 내 확인

### 요약

19일 판에서 다룬 Hy4 Flash(224B, 활성 12B)에 이어 텐센트가 플래그십 Hy4(770B MoE, 토큰당 활성 49B)까지 오픈소스로 풀며 Hunyuan LLM 시리즈의 전면 개방을 완료했다. 라이선스는 Apache 2.0. 두 모델 모두 네이티브 100만 토큰 문맥과 텍스트·이미지·비디오 이해를 지원한다.

Hy4의 구조: 78개 층(표준 FFN 1 + MoE 77, 라우티드 전문가 256개+공유 1개 중 top-8 활성화), 저오버헤드 스페큘레이티브 디코딩용 3.3B DFly2 드래프트 모델 내장. Gated DeepSeek Sparse Attention(Gated DSA)과 층간 희소 인덱스 재사용(IndexCache), identity Hyper-Connections(iHC)가 핵심 기법이다.

회사가 제시한 성능: 금융 분석에서 213명의 금융 전문가 크라우드 평가 평균 3.04/4.0으로 오픈소스 1위(DeepSeek-V4.1-Flash-1017 2.97, Kimi K3.1 Pro 2.68). 검색·사실검증 최적화로 환각률 15.76%→5.45%. 게임 개발은 Hy4 Preview 대비 GameDev +19.1%·GameLogic +9.8%, 내부 TenureTrail(7개 학문·123개 과제)에서 오픈소스 1위. Blender·CAD급 전문 소프트웨어의 GUI·CLI 조작, Office 파일 실시간 협업 편집, 장기 프로젝트 관리를 사용 사례로 든다.

안전 조치로 학습 데이터에서 공격적 사이버 콘텐츠(익스플로잇 생성·리버스 엔지니어링)를 제외하고 방어적 PoC·취약점 복구만 포함했다고 밝혔고, 텐센트 쉬엔우(玄武)의 감사를 언급했다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 회사 발표의 전달형이다.
- **논조 점검:** 크라우드 평가·TenureTrail은 각각 텐센트가 주최하거나 내부 벤치마크다. 환각률 5.45%도 자사 파이프라인 기준이다. 실제 가중치·라이선스 문서는 Hugging Face 페이지에서 확인 가능하며, 이 브리핑은 발표문 요약을 근거로 한다.
- **다른 시각:** 19일 Hy4 flash 공개가 '티저'였고 오늘 전면 개방이 본편이라는 읽기가 가능하다. 770B/49B 활성은 DeepSeek 계열과 같은 체급이라, 오픈소스 플래그십 경쟁이 중국 대형 랩 간 스펙·라이선스 대결로 고착되는 흐름의 연장이다.

**시사점:** 100만 토큰 문맥+네이티브 멀티모달+Apache 2.0 조합이 오픈 가중치 플래그십의 새 기본 사양처럼 되어 가고 있다. 엔진 측의 Hy4 지원(19일 llama.cpp PR)이 770B까지 확장되는지가 다음 관전점이다.
