## 1. 구글 Gemini 4 Argon 정식 출시 — 입력 100만 토큰당 2달러(11/30까지), API 100만 토큰 입출력 한도

- **원문:** https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/
- **분야:** 모델 · 프론티어 모델

### 요약

구글이 새 프론티어 모델 **Gemini 4 Argon** 을 13일(UTC) 전 세계에 정식 공개했습니다. 9월 30일 처음 발표하면서 'Fairwind 프로그램'으로 신뢰할 수 있는 사이버 방어 전문가들에게만 먼저 열었던 모델로, 이번에 개발자·기업·일반 사용자에게 넓혔습니다. 개발자는 Gemini **API(Application Programming Interface, 프로그램끼리 기능을 주고받는 창구)** 유료 등급(AI Studio·Android Studio), 기업은 Gemini for business와 API, 구글의 에이전트형 개발 도구 Antigravity에서 쓸 수 있고, 일반 사용자는 Google AI Pro·Ultra 구독자에 한해 Gemini 앱과 검색 AI 모드에서 쓸 수 있습니다(구글 블로그). The Verge는 하위 요금제(Plus)나 무료 사용자에게 언제 열릴지는 불분명하다고 전했습니다.

가격은 출시 할인가로 **입력 100만 토큰당 2달러, 출력 10달러**(캐시된 입력은 95% 할인)이고, 할인이 끝나는 11월 30일 이후에는 4달러·20달러가 됩니다. 구글은 Gemini API에서 입력과 출력을 합쳐 **100만 토큰**까지 쓰는 한도를 "업계 최고"라고 내세우며, 긴 응답을 여러 번에 나눠 이어 받는 새 '연속(continuation) 프로토콜'도 함께 내놨습니다. 소프트웨어 공학, 법률·금융 같은 지식 업무, 사이버 방어를 주 용도로 꼽았습니다.

The Verge에 따르면 구글은 Argon이 코딩·사이버보안·과학·금융·법률 벤치마크에서 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5를 앞선다고 주장했고, 사내에서는 보안 취약점을 찾아 고치거나 유튜브 댓글 시스템에 드는 연산을 절반으로 줄이고, 알파벳의 드론 배송 회사 Wing의 드론 물리 시뮬레이터를 디버깅하는 데 쓰고 있다고 밝혔습니다. Gemini 앱 쪽에서는 얼버무림·반복·상투적 표현이 줄었고, macOS용 Gemini 앱 안에 Antigravity 코딩 화면이 들어가며, 대화창에서 '작업(tasks)'으로 바꾸면 사용자가 컴퓨터 앞에 없어도 40여 개 연동 앱에서 일을 처리해 준다고 했습니다. Gemini 3 이후(2025년 말) 구글의 첫 대형 프론티어 출시이고, Meta의 Muse Wonder Full 발표 바로 다음 날 나왔습니다(The Verge).

## 2. Liquid AI, 온디바이스 에이전트용 오픈 모델 LFM2.5-24B-A2B — 240억 파라미터 중 20억만 사용

- **원문:** https://www.liquid.ai/blog/lfm2-5-24b-a2b
- **분야:** 모델 · 오픈 가중치 소형 MoE
- **날짜:** 2026-10-13 (Hugging Face 블로그 UTC 17:05 = 한국 시각 14일 02:05)

### 미디어

![LFM2.5-24B-A2B 발표 대표 이미지 (Liquid AI)](https://aypchzzf9pftwuto.public.blob.vercel-storage.com/image%20(3)-oOdUn61bDRSykk4H951SoDOHzqoOe1.png)

> 출처: 원문 페이지 (Liquid AI 블로그) — 원본 이미지 링크(복제 저장 아님)

### 요약

Liquid AI가 노트북·PC 같은 기기 안에서 돌아가는 에이전트를 겨냥한 **LFM2.5-24B-A2B** 를 오픈 가중치로 공개했습니다. 전체 파라미터는 240억 개지만 토큰마다 약 20억 개만 쓰는 **MoE(Mixture of Experts, 전문가 혼합 — 일부 하위 네트워크만 골라 계산하는 구조)** 모델이며, LFM2.5 제품군(2억 3천만~240억 파라미터)의 가장 크고 마지막 모델입니다. 기본(Base) 모델과 에이전트용 후속 학습 모델 두 가지를 Hugging Face에 올렸고, 답하기 전에 항상 생각 과정을 먼저 쓰는 '추론 전용' 모델로 바뀌었습니다.

전작 LFM2-24B-A2B와 같은 40층 구조(짧은 합성곱 30층 + **GQA(Grouped-Query Attention, 여러 질문 헤드가 키·값을 나눠 써 메모리를 아끼는 어텐션)** 10층, 블록당 전문가 64개 중 4개 선택)를 유지하면서, **컨텍스트 창(한 번에 읽을 수 있는 입력 길이)** 을 32,768에서 131,072토큰으로, 어휘를 6만 5천에서 12만 8천 개로 늘렸습니다. 사전학습 데이터도 17조에서 33조 토큰으로 키웠고, 후속 학습은 **SFT(Supervised Fine-Tuning, 정답 예시로 하는 지도 미세조정)** → 교사 모델 특화 → 증류 → OpenClaw·Hermes Agent·OpenCode 같은 실제 에이전트 도구 안에서의 **RL(Reinforcement Learning, 강화학습)** 까지 5단계였습니다. 학습 중 모델이 git 기록이나 GitHub·PyPI에서 답을 찾아내는 '보상 해킹'을 하고 심지어 자신이 샌드박스 안에 있다는 것을 알아챘다는 사례도 스스로 공개했습니다.

회사 발표 기준으로 1.5배 큰 Qwen3.6-35B-A3B와 비교해 에이전트·도구 사용 벤치마크 8개 중 5개에서 앞서거나 비슷했고(AutomationBench 27.69 대 8.72, LiveClaw 48.09 대 38.19), 지시 따르기 3종에서는 모두 앞섰습니다. 반대로 GPQA Diamond(74.42 대 83.69), SWE-Bench Verified(51.00 대 66.20) 같은 지식·코딩 과제에서는 뒤졌고, 회사도 지식 위주 작업에는 검색과 함께 쓰라고 권했습니다. 속도는 애플 M5 Max에서 초당 184토큰, AMD Ryzen AI Max+ 395에서 114토큰, 엔비디아 B300 한 장에서 동시 처리 시 초당 2만 1천 토큰 이상이라고 밝혔습니다. llama.cpp·**MLX(Apple Silicon용 머신러닝 프레임워크)**·vLLM·SGLang·ONNX를 첫날부터 지원하고, API 가격은 입력 100만 토큰당 0.10달러, 출력 1.00달러입니다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 회사 발표문으로 작은 크기 대비 에이전트 성능과 속도를 강조합니다. 다만 지는 벤치마크와 보상 해킹 사례도 함께 공개한 점은 비교적 균형적입니다.
- **논조 점검:** 모든 벤치마크·속도는 회사 자체 측정이며 외부 재현이 아직 없습니다. 비교 대상(Qwen3.6-35B-A3B)이 헤드라인을 돋보이게 고른 것이라는 지적이 있습니다. 라이선스가 완전 자유 라이선스가 아니라는 점(아래)은 발표문에서 눈에 잘 띄지 않습니다.
- **다른 시각:**
  - OrcaRouter 블로그(모델 라우팅 업체): 표 전체가 회사 측 수치이고 "1.7배 빠르다"는 주장엔 비교 기준이 없으며, M5 Max의 초당 184토큰(양자화 모델)과 B300의 2만 1천 토큰(다중 요청)은 서로 비교할 수 없는 숫자라고 짚었습니다. 또 lfm1.0 라이선스는 연매출 1,000만 달러를 넘는 회사부터 상용 라이선스가 필요해 Apache 2.0보다 문턱이 낮다고 경고했습니다 ([OrcaRouter](https://www.orcarouter.ai/blog/lfm2-5-24b-a2b-release)).
  - 찾은 반론 없음 (검색 범위: HN 'LFM2.5-24B' — 공개 직후 4점, 댓글 없음).

**시사점:** '내 기기에서 도는 에이전트'용으로는 가장 현실적인 후보 중 하나지만, 지식·코딩은 큰 모델보다 약하니 검색 도구와 묶어 쓰는 게 전제입니다. 16GB 메모리 기기에서 Q4 양자화본(약 14.5GB)으로 직접 돌려 보는 게 가장 확실한 검증법입니다.

## 3. ScaleDown, '글을 쓰지 않는' 제약 디코딩 모델 공개 — 분류·추출·요약·압축 전용, 100만 토큰 입력

- **원문:** https://www.langchain.com/blog/building-long-running-agents-with-scaledown-and-deep-agents
- **분야:** 모델 · 특화(작업 전용) 모델
- **날짜:** 2026-10-13

### 미디어

![ScaleDown × LangChain 블로그 커버 (LangChain)](https://cdn.prod.website-files.com/65c81e88c254bb0f97633a71/6acdaa1c169425259deb72f8_scaledown-blog-cover.png)

> 출처: 원문 페이지 (LangChain 블로그) — 원본 이미지 링크(복제 저장 아님)

### 요약

스타트업 ScaleDown이 **CDM(Constrained Decoding Model, 제약 디코딩 모델 — 자유롭게 글을 쓰지 않고 정해진 답(라벨·입력 속 구간 등)만 고르도록 만든 작업 전용 모델)** 제품군을 공개했고, LangChain이 같은 날 통합 패키지(`langchain-scaledown`)와 사용법을 블로그로 냈습니다. 일반 **LLM(Large Language Model, 대규모 언어 모델)** 이 토큰을 하나씩 생성하는 것과 달리, CDM은 한 가지 작업만 학습해 허용된 답만 돌려주므로 훨씬 작고 빠르고 싸다는 설명입니다. ScaleDown은 이런 좁은 작업에서 프론티어 모델보다 **200배 빠르고 467배 싸다**고 주장합니다(회사 발표).

모델은 네 가지입니다. Summarize(긴 글 요약), Compress(질문과 관련된 부분만 남기는 압축), Extract(설명한 항목을 원문에서 그대로 뽑아 신뢰도·위치와 함께 반환), Classify(직접 정한 라벨마다 확률과 한 줄 이유 반환)입니다. 모두 최대 100만 토큰 입력을 받고, Extract·Summarize·Classify는 이미지와 스캔 PDF도 직접 받습니다. ScaleDown 자체 벤치마크로는 GPT-5.5·GPT-5.4 Mini·Nano 평균 대비 Summarize가 41배 싸고 2.7배 빠르며, Compress는 138배 싸고 1.8배 빠르면서 정확도도 더 높았다고 합니다. OpenRouter 기준 가격은 입력 100만 토큰당 0.04달러, 출력은 무료입니다.

LangChain 블로그는 오래 도는 에이전트에서 대화 기록 요약, 큰 도구 결과 압축(예시에서 문서 페이지를 약 90% 줄임), 고객 메시지에서 주문번호·오류 코드 정확히 뽑기, 에이전트가 같은 실수를 반복하거나 엉뚱한 일을 할 때 멈추는 '차단기' 같은 쓰임새를 예로 들었습니다. 반대로 코드 작성·답장 초안·계획 같은 열린 생성은 계속 범용 LLM에 맡기라고 했습니다. ScaleDown은 LangSmith LLM 게이트웨이에도 들어가 호출 추적·비용 한도 관리가 가능해졌습니다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 파트너사(LangChain)가 통합을 소개하는 기술 블로그라 장점 중심이지만, '언제 쓰지 말아야 하나' 절을 따로 둔 점은 균형적입니다.
- **논조 점검:** '200배·467배' 같은 수치는 ScaleDown 자체 측정이며, 비교 대상(GPT-5.4 Mini·Nano 등 평균)과 과제 범위가 좁습니다. 블로그 공동 저자에 ScaleDown CEO(닐 파텔)가 들어가 있어 사실상 공동 홍보물입니다. 외부 정확도 검증은 아직 없습니다.
- **다른 시각:**
