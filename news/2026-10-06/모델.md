## 1. Reflection AI 'Beam' — 501B/활성 23B MoE 오픈웨이트, SWE 80.9

- **원문:** https://techcrunch.com/2026/10/05/reflection-debuts-beam-a-open-weight-ai-model-to-rival-chinese-models-at-lower-compute-cost/
- **분야:** 모델 · 오픈웨이트 LLM
- **날짜:** 2026-10-05

### 요약

브루클린 기반 스타트업 Reflection AI가 첫 프런티어급 **오픈웨이트(open-weight, 학습된 가중치를 공개해 누구나 내려받아 돌릴 수 있는)** 모델 **Beam** 을 공개했습니다.

- **구조:** 총 5,010억(501B) 파라미터 중 토큰당 230억(23B)만 활성화되는 **MoE(Mixture of Experts, 전문가 혼합 — 여러 하위 네트워크 중 일부만 골라 계산해 비용을 줄이는 구조)**. 텍스트 전용.
- **학습:** 23.8조 토큰 사전학습, 고연산 **강화학습(RL, 보상 신호로 행동을 개선하는 학습)** 으로 추론·코딩·**에이전트 작업(agentic tasks, 도구를 쓰며 여러 단계를 스스로 수행하는 작업)** 에 최적화.
- **컨텍스트:** 100만 토큰 **컨텍스트 윈도(context window, 한 번에 읽고 기억할 수 있는 입력 길이)**.
- **성능 주장:** 브리핑 기준 SWE(소프트웨어 엔지니어링 벤치마크, 실제 깃허브 이슈 해결 능력 평가) **80.9**. 고급 추론 벤치마크에서 Z.ai의 GLM-5.2(총 744B/활성 40B)와 대등하면서 **추론 연산(inference compute, 답을 생성할 때 드는 계산량)** 은 3~4배 적다고 주장합니다. Thinking Machines Lab의 Inkling 대비 코딩 테스트 4종에서 앞선다고 하나, Inkling은 멀티모달이라 직접 비교엔 한계가 있습니다.

Reflection은 2024년 구글 딥마인드 출신이 세운 회사로 약 47억 달러를 조달했고, 기업·국가 대상 **"AI 팩토리"(자체 데이터로 맞춤 모델을 학습·운영하는 현지 AI 시스템)** 를 사업 모델로 내세웁니다. 한국 신세계그룹과 **소버린 AI(sovereign AI, 국가·기업이 자체 통제하는 AI)** 팩토리 협력을 시험 중이라는 점도 언급됐습니다. 가중치와 기술 문서는 이달 중 공개 예정입니다.

**시사점:** 딥시크·큐원 등 중국 오픈 모델에 대한 "서구권 대안" 경쟁이 본격화. 가중치 공개 시 독립 벤치마크 확인이 필요합니다.

## 2. Reka AI 'Rho-1' — 19B 옴니 모델 (텍스트·이미지·영상·로봇 제어 단일 모델)

- **원문:** https://the-decoder.com/reka-ais-omni-model-rho-1-handles-text-images-video-and-robot-control-in-a-single-model/
- **분야:** 모델 · 멀티모달/월드모델
- **날짜:** 2026-10-05

### 요약

Reka AI가 190억(19B) 파라미터 **옴니 모델(omni-model, 여러 형태의 입력·출력을 하나의 모델이 모두 처리)** **Rho-1** 의 리서치 프리뷰를 공개했습니다. 텍스트·이미지·영상·**로봇 제어 액션(robot control actions, 로봇 관절·움직임 명령)** 을 하나의 신경망에서 처리·생성하며, 모든 **모달리티(modality, 데이터 형태)** 를 토큰으로 바꿔 하나의 공유 컨텍스트에서 다룹니다. 별도 **툴 호출(tool call)** 이나 외부 모델로 작업을 넘기지 않습니다.

실시간으로 연속 영상을 생성하면서 새 지시에 즉시 반응할 수 있고, 카메라 영상을 예측하는 같은 가중치가 로봇 움직임도 구동합니다. 부족한 로봇 학습 데이터 문제는 일반 인터넷 영상에서 제어 신호를 추출하는 **역동역학 모델(inverse dynamics model, 화면 변화로부터 어떤 동작이 있었는지 역으로 추정하는 모델)** 로 우회했습니다. H100 GPU 320장으로 약 3개월 학습했습니다.

**시사점:** 업계의 **월드 모델(world model, 세계가 어떻게 변하는지 예측·시뮬레이션하는 모델)** 흐름 속에서, 비교적 작은 규모로 로보틱스까지 통합한 시도입니다.

## 3. Interfaze 'interfaze-1-lite' — OCR·음성·구조화 추출용 오픈웨이트

- **원문:** https://runtimewire.com/article/interfaze-1-lite-open-weight-model
- **분야:** 모델 · 문서/음성 특화
- **날짜:** 2026-10-05

### 요약

샌프란시스코 스타트업 Interfaze(구 JigsawStack)가 **interfaze-1-lite** 를 **Apache 2.0(상업적 이용이 자유로운 오픈소스 라이선스)** 으로 허깅페이스에 공개했습니다. 문서 **OCR(광학 문자 인식)**, **STT(음성→텍스트 변환)**, **구조화 추출(structured extraction, 문서에서 정해진 JSON 스키마로 값을 뽑아내는 것)** 등 "검증 가능한 출력"이 필요한 작업을 겨냥합니다.

- **특징:** 답과 함께 **신뢰도 점수(confidence score)** 와 **바운딩 박스(bounding box, 이미지에서 해당 텍스트가 위치한 사각형 좌표)** 같은 근거 메타데이터를 반환 → 신뢰도가 낮은 행만 사람 검토로 돌리는 워크플로가 가능.
- **구조:** **MoA(Mixture of Architecture)** — 추론 코어가 요청을 해석하고, 문서 판독·음성 인식·객체 탐지 등 **전문 모델(specialist)** 에 일을 나눠 맡기는 방식.
- **사양:** 80GB GPU 1장(H100 등)에서 구동, 128K 컨텍스트 / 최대 32K 출력. 화자 분리(speaker diarization), GUI 탐지, 번역 등 지원. API 가격은 입력 100만 토큰당 0.85달러, 출력 1.50달러.
- **벤치마크(회사 발표):** olmOCR 83.8%(Claude-Sonnet-5 83.5%를 근소하게 앞섬), 구조화 출력 81.5% 등. 일부 항목은 자체 보고 수치이며 격차가 작은 경우도 있습니다.

**시사점:** "유창한 답"보다 "검증 가능한 답"을 파는 실용형 모델. 실제 도입 시에는 자기 문서로 신뢰도 점수의 보정 상태를 직접 확인해야 합니다.
