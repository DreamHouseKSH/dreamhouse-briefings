### 요약

Citi가 개정한 온라인 약관에서, 고객이 은행 로그인 정보를 넘긴 외부 AI 에이전트가 의도하지 않은 곳으로 송금하더라도 그 행위를 고객이 승인한 것으로 간주한다는 조항이 확인됐다고 FourWeekMBA가 전했다. TechCrunch는 같은 방향으로 움직인 대형 은행이 4곳 더 있다고 보도했다.

- **기사 논조:** 경계 — 각 항목에 원문 링크와 출처를 붙인 브리핑 형식이며, 인과 관계는 짓지 않는다고 명시한다.

## 3. Cloudflare Agents SDK 0.34 — 도구가 사람의 승인을 기다리는 동안 서버를 깨우지 않는다

- **원문:** https://trending.llmnet.nl/en/briefing/2026-11-22 (llmnet 일일 브리핑, @CFchangelog 공식 포스트 — 신뢰도 '중간' 표기)
- **분야:** IT · 클라우드/개발자 인프라
- **최초 게시:** llmnet 2026-11-22 (원 포스트 11-21~22)
- **시간 판정:** 구간 경계(원 포스트 시각 미확인, 브리핑 발행일 기준)

### 요약

Cloudflare 변경 로그 계정이 Agents SDK v0.34.0을 알렸다. Pi 1.6으로 업그레이드되면서 도구(tool)가 사람의 응답이나 마감 시각을 기다리는 동안 Durable Object(Cloudflare의 상태 유지 컴퓨팅 단위)를 깨워 두지 않아도 되게 됐다. 승인 대기 중에도 실행 중인 서버 비용이 들지 않는 설계다. 함께 언급된 사례로, Cloudflare 위에서만 돌고 플레이어가 없으면 잠드는 오픈소스 마인크래프트 Java 서버(@sshkeda, 11.6만 뷰), Code Mode로 MCP 토큰을 117만 개에서 1,000개로 줄였다는 @hustle_fred의 전언(2차 전달)이 있다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 회사 발표 전달형이다.
- **논조 점검:** 토큰 절감 수치는 2차 전달이며 원문 미확인이라고 llmnet 자체가 밝힌다. 성능·비용 효과는 워크로드마다 다르다.
- **다른 시각:** '승인 대기'는 어제 판 Hermes PR 항목과 같은 방향의 업계 흐름이다. 에이전트가 멈춰 서서 사람을 기다리는 것을 인프라 비용 문제로 풀겠다는 접근이다.

**시사점:** 사람 승인 단계를 비용 0에 가깝게 만들수록 '에이전트가 먼저 묻는' 설계가 기본값이 되기 쉽다. 승인 UX와 감사 로그가 인프라 선택 기준으로 올라온다.
