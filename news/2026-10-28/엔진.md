## 1. Ollama 0.40.12, LFM3·d1 2B를 Apple 하드웨어부터 지원

- **원문:** https://github.com/ollama/ollama/releases/tag/v0.40.12
- **분야:** 엔진 · 로컬 모델 실행
- **날짜:** 2026-10-27 09:07:12 KST (GitHub 릴리스 시각)

### 요약

Ollama 0.40.12는 Liquid AI의 LFM3 계열과 d1 2B 지원을 추가했다. 텍스트뿐 아니라 이미지·음성을 다루는 계열을 같은 실행 도구에서 접근할 수 있게 한 변화다. 다만 이번 릴리스에서 LFM3와 d1 2B 지원은 **Apple 하드웨어에 한정**되며, Linux와 Windows는 후속 지원 예정이라고 명시했다.

릴리스는 LFM3 텍스트 모델의 256K 토큰 문맥과 음성 계열의 18개 언어 처리를 소개한다. 이는 모델·지원 기능 설명이지 모든 기기에서 해당 길이를 빠르게 처리한다는 보장은 아니다. 모델의 세부 공개 범위는 [오늘 모델 브리핑](모델.md)에서 별도로 다룬다.

그 밖에 Apple Silicon에서 Gemma 4·Flint·Laguna 입력 처리 개선, MLX(애플 기기의 머신러닝 계산 프레임워크)에서 DFlash2 초안 모델을 이용한 추측 디코딩 지원, OpenCode v2 연동과 Kimi CLI의 도구 전용 응답 처리 수정이 포함됐다. 이 브리핑에서는 설치나 자체 속도 시험을 수행하지 않았다.

- **논조 점검:** 플랫폼 제한을 빼면 모든 운영체제에서 즉시 사용할 수 있다는 오해가 생긴다. 속도 개선의 공통 배율은 제시되지 않았다.

  - 예상 쟁점: 실제 업무에서는 한국어 품질·메모리 사용·도구 호출 정확도를 사용하는 기기와 데이터로 따로 확인해야 한다.

**시사점:** 새 모델 공개와 실행 엔진의 지원 완료는 별개다. 이번에는 운영체제별 지원 여부부터 확인하는 것이 우선이다.

## 2. llama.cpp, RPC 메시지 오류가 서버 전체를 종료시키는 경로 수정

- **원문:** https://github.com/ggml-org/llama.cpp/pull/31204
- **분야:** 엔진 · 안정성
- **날짜:** 2026-10-27 22:04:56 KST 병합 / b11935 릴리스 2026-10-28 02:15:04 KST

### 요약

llama.cpp는 RPC(Remote Procedure Call, 다른 프로세스나 컴퓨터에 작업을 요청하는 방식) 서버가 가변 길이 메시지를 읽을 때 발생하는 예외 처리 누락을 수정했다. 수신 길이가 버퍼가 표현할 수 있는 최대 범위를 넘으면 기존 메모리 할당 실패 처리와 다른 종류의 오류가 발생해 서버 프로세스가 종료될 수 있었다.

수정은 해당 오류를 잡아 잘못된 연결을 끊고 서버는 계속 동작하도록 하는 내용이다. 작성자는 일반 빌드와 메모리 오류 탐지 도구를 적용한 빌드에서 큰 길이를 가진 메시지를 넣은 뒤 후속 연결을 처리하는 시험을 했다고 보고했다. 이는 개발자가 공개한 재현 시험이며 이 브리핑의 독립 검증 결과는 아니다.

변경은 [b11935 릴리스](https://github.com/ggml-org/llama.cpp/releases/tag/b11935)에 포함됐다. 이번 확인 자료만으로 별도의 취약점 식별 번호, 실제 악용 사례 또는 모든 배포판의 반영 여부를 확정할 수는 없다. 일반 채팅 서버 전체의 문제라고 확대하지 않고 RPC 기능을 사용하는 구성의 수정으로 구분한다.

### 논조·다른 시각

- **기사 논조:** 중립 — 오류 원인과 제한된 수정·시험 결과를 설명한다.
- **논조 점검:** 실제 서비스 노출·배포 상태와 개발자의 재현 시험은 다르다. 서버 종료 가능성을 곧바로 데이터 유출로 해석할 근거는 없다.
- **다른 시각:** 찾은 반론 없음 (검색 범위: 해당 변경 요청과 공식 릴리스). 예상 쟁점: RPC를 사용하는 운영자는 수정 버전 적용뿐 아니라 연결 허용 범위와 장애 후 복구 절차도 함께 점검할 필요가 있다.

**시사점:** 작은 예외 처리 수정도 공유 추론 서비스의 가용성에 영향을 줄 수 있지만, 실제 영향은 RPC 사용 여부와 배포 버전에 달려 있다.
