## 1. Anthropic, Messages API를 Python에서 Rust로 이전 — Claude 에이전트 팀이 구·신 구현 차이를 추적

- **무슨 일인가:** Anthropic이 Claude 모델을 서비스하는 Messages API를 Python에서 Rust로 옮겼다고 밝혔다. 기존 서비스를 기준(reference)으로 삼아, Claude 에이전트 팀이 실제 요청으로 두 구현을 비교하고 차이를 찾아 고치며 사람이 검토했다는 방식이다. The Neuron은 요청당 프로세서 사용량 약 70% 감소, 첫 토큰 중앙 대기시간 20% 단축으로 전했고, InfoWorld는 "다운타임 없이" 이전했다고 보도했다. (Anthropic 연구 블로그 2026-11-25, The Neuron·TechRepublic·InfoWorld 2026-11-26 = 정규 구간 내. 수치는 보도 인용이며 블로그 본문 세부는 직접 읽지 못함)
- **논조:** "Claude가 Claude를 서비스하는 API를 다시 썼다"는 자기 참조 서사와, 검증이 쓰기보다 어려웠다는 TNW식 해석이 함께 나온다.
- **다른 시각:** 성능 수치는 자사 보고다. 에이전트가 찾은 차이가 모든 엣지 케이스를 덮는지는 독립적으로 확인되지 않았다.
- **시사점:** '옛 서비스를 정답지로 두고 에이전트가 동작 차이를 사냥하는' 이전 패턴은 다른 팀도 따라 할 수 있다. 에이전트 활용의 무게중심이 코드 작성에서 검증으로 이동하는 사례다.

## 2. OpenClaw 2026.11.10 — 채팅 안 Deep Research, 로컬 Knowledge 볼트, 브라우저 인계, 그리고 '확장 안정' 트랙

- **무슨 일인가:** llmnet이 릴리스 노트를 직접 읽은 바에 따르면 v2026.11.10은 PR 7,671건, 직접 커밋 633건, 기여자 349명을 인용한다. Deep Research는 여러 웹 출처나 로컬 문서를 조사해 인용 보고서를 돌려주며, 출처가 엇갈리면 인용문을 나란히 놓고 '미해결' 항목을 따로 적는다. 기본 켜짐, 보고서는 7일 보관. Knowledge는 대화·노트·파일을 링크된 로컬 마크다운 볼트로 만들며, plugins.slots.memory를 'knowledge'로 설정해야 켜지는 옵트인이고 기존 memory-core 데이터는 건드리지 않는다. Browser handoff는 로그인 벽, 2FA, CAPTCHA에서 사용자가 에이전트 제어 탭을 '직접 제어/해제'로 넘겨받는 기능이다. 별도로 v2026.10.34가 게이트웨이 전용 '확장 안정(LTS 격)' 릴리스로 나왔고, 10월 말 기준에 핵심 보안·안정성 수정과 GPT-6.2 Astra·Sol 지원을 담았다. (llmnet 데일리 2026-11-26 = 구간 경계; 릴리스 페이지 두 곳 직접 확인, 신뢰도 high)
- **논조:** 어제 보류된 11.7 건과 달리 이번에는 릴리스 노트가 채워진 정상 공개다. 빠른 트랙과 차분한 트랙을 고르게 한다는 점이 강조된다.
- **다른 시각:** Knowledge는 메모리 설정을 건드리는 기능이라 노트를 먼저 읽을 것을 권한다. 옵트인이므로 선택 없이는 변화가 없다.
- **시사점:** 에이전트 프레임워크가 LTS 개념을 도입하기 시작했다. 홈랩 게이트웨이 운영자는 신기능 트랙과 안정 트랙 중 하나를 고를 수 있다.

## 3. Cloudflare, 'Search for Agents' 토글 하나와 무료 Workers의 이메일 전송 지원

- **무슨 일인가:** Cloudflare가 X에서, 토글 하나로 사이트를 AI 에이전트가 검색할 수 있게 한다고 밝혔다. 콘텐츠 자동 색인, 발견 가능한 검색 API, HTTP QUERY 메서드 지원을 포함한다. @CloudflareDev는 무료 Workers 플랜에서 이메일 전송(Email Sending)을 쓸 수 있다고 알렸다. (llmnet 데일리 2026-11-26 = 구간 경계; 첫 포스트는 직접 읽었으나 문서는 읽지 못해 신뢰도 medium)
- **논조:** 사이트 소유자가 에이전트에게 검색 가능성을 열어 주는 기능으로 소개된다.
- **다른 시각:** llmnet은 테스트 존에서 먼저 시험하고 에이전트에게 무엇이 노출되는지 확인할 것을 권한다. 토글은 되돌릴 수 있다.
- **시사점:** 웹이 사람용 검색에서 에이전트용 검색 API 제공으로 확장되는 흐름이다. 무료 이메일 전송은 소규모 알림 루틴을 단순하게 만든다.
