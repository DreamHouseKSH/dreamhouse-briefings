- **시간 판정:** 시간 미확인 참고. 정규 구간 내 확정 기사 수에서 제외.. 약관 시행일도 11월9일이나 발표 시각 증거는 아님.

### 요약

LG AI연구원이 K-EXAONE 2.5의 API를 무료로 공개했다. 지난 8월 버전에 추가 학습한 기술 검증 모델로, 공식 설명은 코딩·추론·업무 자동화 능력에 초점을 맞춘다. 여기서 API(Application Programming Interface, 프로그램이 외부 기능을 호출하는 접속 규칙)는 모델 서버에 요청해 결과를 받는 접속 방식으로, 모델 가중치를 내려받아 자체 서버에서 실행하는 공개와는 다르다.

문서상 이 모델은 텍스트 전용이며 입력과 생성량 합계의 최대 문맥은 52만4288 토큰이다. OpenAI 호환 형식으로 접속하며, 답변 전 추론은 항상 활성화된다. LG가 발표한 벤치마크는 공개 데이터셋에 대한 자체 측정치다. 이러한 결과만으로 실제 한국어 업무 전체에서 경쟁 모델보다 낫다고 일반화할 수 없다.

특히 무료라는 설명과 이용 권한을 구분해야 한다. 11월9일자 현행 영문 약관 2.1항은 비상업적 이용만 허용하고, 제품·서비스에 통합해 제3자가 모델을 호출하거나 입력을 제출하도록 하는 사용을 금지한다. 2.3항에는 입력·출력을 모델 학습에 사용할 수 있으며 플랫폼에서 학습 사용을 거부할 수 있다는 조건도 있다. 상업 배포나 내부 데이터 투입 전 별도 약관 검토가 필요하다.

### 논조·다른 시각
- **기사 논조:** 발표문은 무료 접근성과 성능을 홍보한다. 공식 API 문서와 약관을 함께 읽으면 상용 배포 권한·가중치 제공까지 의미하지 않음을 알 수 있다.
- **논조 점검·다른 시각:** 자체 벤치마크와 실제 서비스 성능·라이선스 적합성은 별개다. 독립 재현 평가를 확인하지 못했다. 한국어·영문 약관 차이 발생 시 한국어 우선이라는 조항도 있어 최종 도입 시 원문을 확인해야 한다.

**시사점:** 연구·비상업적 평가의 비용 장벽은 낮아졌지만, 무료 API를 곧바로 상용 제품의 대체재로 계산하면 안 된다.
