### 요약

OpenAI가 보안 연구용 GPT-6 Cyber를 일부 승인된 Daybreak Red 고객에게 먼저 제공한다고 발표했다. 접근 경로는 API(Application Programming Interface, 프로그램끼리 기능을 주고받는 창구)와 Codex이며, 전체 Daybreak Red 고객으로 확대하는 것은 향후 계획이다. 일반 이용자에게 제한 없이 공개된 모델은 아니다.

회사 발표 기준 ExploitGym 평가 점수는 GPT-5.6 Cyber의 32.1%에서 48.5%로 높아졌다. 이는 특정 취약점의 악용 가능성을 시험하는 평가 결과이지 모든 보안 작업의 성공률이 아니다. OpenAI는 자사 위험 대비 체계에서 사이버 역량을 기존 High보다 높은 Critical로 분류했다. 이 분류는 정부 인증이나 안전성 보증이 아니다.

회사는 허가된 작업 범위를 지키도록 학습을 강화하고, 오용 감시와 승인된 네트워크의 접근 제한 등을 함께 적용한다고 설명한다. 평가상 높은 경계 준수율도 실제 환경에서 일탈이 전혀 없다는 증거가 될 수 없다. 격리된 실행 환경, 고위험 행동 검토와 사람의 감독을 계속 권고한다.

### 논조·다른 시각

- **기사 논조:** 긍정과 경계가 섞임. 방어 성능과 작업 범위 준수 개선을 강조하면서 악용 위험 때문에 접근을 제한한다.
- **논조 점검:** 성능·안전성 수치는 회사 자체 평가이며 독립 재현하지 않았다. 초기 제한 제공과 향후 확대 계획을 구분해야 한다.
- **다른 시각:** [Mozilla의 Firefox 159 보안 공지](https://www.mozilla.org/en-US/security/advisories/mfsa2026-118/)에서 OpenAI 연구자가 보고한 여러 수정 항목을 확인했다. 이는 실제 수정 기록을 뒷받침하지만 GPT-6 Cyber 전체 성능 수치를 독립 검증한 자료는 아니다. 공지는 10월 27일자이므로 오늘 새 패치로 재포장하지 않았다.

**시사점:** 보안 모델의 비교 기준은 발견 능력뿐 아니라 승인 범위, 접근 통제와 사람이 검증할 수 있는 결과다. 자체 평가 점수와 현장 안전성을 같은 지표로 읽지 않는 편이 정확하다.
