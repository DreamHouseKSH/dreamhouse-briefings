## 1. OpenAI 'GPT-6.2 Astra·Sol' 공개 — Astra 가격 20% 인하, Bedrock에서도 당일 제공

- **원문:** https://www.theverge.com/tech/1035483/openai-releases-its-updated-gpt-6-2-astra-model · https://docs.litellm.ai/blog/gpt-6-2-astra-sol
- **분야:** AI 모델
- **최초 게시:** OpenAI 2026-11-17, The Verge 11-17 17:45 UTC
- **시간 판정:** 정규 구간 내 확인

### 요약

OpenAI가 17일 프론티어 모델의 업데이트 GPT-6.2 Astra와 차상위 모델 GPT-6.2 Sol을 동시에 공개했다. 회사 설명에 따르면 Astra는 슬라이드·스프레드시트·문서 생성이 "덜 AI처럼 읽히도록" 개선됐고 템플릿 준수가 좋아졌으며, 웹사이트·게임·3D 디자인 코딩이 강화됐다. Sol은 전작보다 "더 똑똑하고 효율적"이라고 한다.

가격이 눈에 띈다(LiteLLM 정리). Astra는 입력 100만 토큰당 8달러, 출력 40달러(27.2만 토큰 초과 시 16/60달러)로 전작 대비 20% 인하됐고 캐시 입력은 60% 저렴하다. 회사 벤치마크 'Agents' Last Exam'에서 GPT-6 Astra 대비 5.2점 높다. Sol은 가격을 전작(GPT-6.1 Sol) 그대로 유지(입력 2달러, 출력 10달러)하면서 FrontierCode 2.0에서 Astra에 0.5점 차로 근접했다. 두 모델 모두 배치 50% 할인, Fast 모드는 2배 요금이며, AWS에서도 당일 정식 제공(Amazon Bedrock GA)됐다. 시스템 카드도 함께 공개됐다.

### 논조·다른 시각

- **기사 논조:** 사실 전달 — 출시 소식과 스펙 정리다.
- **논조 점검:** 'Agents' Last Exam +5.2점'과 'FrontierCode 2.0 0.5점 차'는 회사 발표 수치다. 독립 벤치마크는 출시 직후라 아직 없다.
- **다른 시각:** 프론티어 모델의 20% 가격 인하는 상위 모델 시장의 가격 압박을 의미한다. Qwen4-Max(3번) 같은 저가 공세와 맞물린 방어로 읽힐 수 있다.

**시사점:** 상위 모델 2종 동시 갱신 + 가격 인하 + 멀티클라우드(Bedrock) 당일 배포는 '플랫폼 전쟁'의 양상이다. MS가 같은 날 Foundry에 GPT 6.2를 탑재한다고 발표한 것도 같은 흐름이다.

## 2. MS, MAI 모델 7종 공개 — 플래그십 코딩 모델 'Code 2' GitHub Copilot에 정식 탑재

- **원문:** https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem/ · https://microsoft.ai/news/microsoft-ignite-2026-mai-keynote/
- **분야:** AI 모델 · 마이크로소프트 자체 모델
- **최초 게시:** 2026-11-17 (Ignite MAI 키노트)
- **시간 판정:** 정규 구간 내 확인

### 요약

마이크로소프트 AI(MAI)가 Ignite에서 "확장 가능한 가격-성능의 세계적 수준 모델 7종"을 공개했다. 나델라 키노트에서 두 가지가 조명됐다.

① **Code 2·Code 2 Flash** — 새 플래그십 에이전트 코딩 모델 패밀리. Code 2는 프로덕션 반영, 심층 디버깅, 다중 파일 구현, 저장소 전체 추론, UI 작업을 "프론티어 비용의 일부"로 한다는 게 회사 주장이다. Code 2 Flash는 코드 설명·부분 수정·반복 작업용 고속 모델이다. 둘 다 오늘부터 GitHub Copilot(모델 선택기와 Copilot Fusion)과 Foundry에서 정식 제공된다. ② **Cyber 2 Flash** — "플래시 크기로 프론티어급 성능"을 내는 보안 모델로, 에이전트 보안 시스템 Perception과 통합된다. 이 밖에 이미지 모델 MAI Image 2.7("프론티어 품질을 일부 비용으로")도 발표됐다. 나델라는 또 'MAI Licensed Weights'를 공개했다 — 신뢰 고객이 Frontier Co를 통해 MAI 모델의 가중치를 받을 수 있는 제도다. 사전학습은 컴퓨트 효율, 배포는 토큰 효율을 목표로 "실제 작업 성능으로 프론티어 곡선에 점을 더 찍겠다"고 말했다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 자사 키노트 발표다.
- **논조 점검:** '프론티어 비용의 일부'와 성능 주장은 회사 발표이며 구체적 벤치마크 수치는 키노트에 없었다. 7종 전체의 세부 스펙은 MAI 키노트 전문에서 확인해야 한다.
- **다른 시각:** MAI 가중치 라이선스는 오픈웨이트 진영(Meta 등)과 MS 자체 모델의 관계를 재정의하는 움직임이다. 동시에 MS는 Foundry에 GPT 6.2와 메타 최신 모델도 탑재한다 — 자체 모델과 개방형 플랫폼의 투트랙이다.

**시사점:** MS가 '모델 중립 플랫폼'과 '자체 모델'을 동시에 키우는 전략이 구체화됐다. GitHub Copilot 기본 제공은 Code 2에 수백만 개발자 채널을 열어준다.

## 3. 알리바바 'Qwen4-Max' 기업 시장 공략 — 작업당 비용 62% 절감 주장, 벤치마크는 들쭉날쭉

- **원문:** https://venturebeat.com/technology/alibabas-qwen4-max-cuts-ai-task-costs-but-benchmarks-show-an-uneven-challenge-to-frontier-rivals
- **분야:** AI 모델 · 중국 모델
- **최초 게시:** VentureBeat 2026-11-17 04:36 PT (11-17 21:36 KST)
- **시간 판정:** 정규 구간 내 확인

### 요약

알리바바가 플래그십 모델 Qwen4-Max로 기업 시장을 공략한다고 VentureBeat이 17일 보도했다. 텍스트·이미지·영상 입력과 최대 100만 토큰 컨텍스트를 지원하며, 회사 내부 평가(Work360: 26개 직역, 182개 하위 분야, 721개 전문 분야의 업무 프레임워크)에서 작업당 평균 비용을 Qwen3.8-Max의 4.43달러에서 1.67달러로 약 62% 낮췄다는 게 핵심 주장이다. Work360 점수는 47.74→52.69로 10.4% 올랐고, Xhigh 추론 설정에서 토큰 소모는 약 24%, High에서는 35% 줄었다고 한다(터미널 벤치 4.0에서는 48~49% 절감).

API 가격은 입력 100만 토큰당 1.50달러, 출력 4.50달러로 앤트로픽·OpenAI·구글의 주요 대안보다 싸다. 다만 이번에는 오픈웨이트가 아니다 — Qwen4-Max는 독점(proprietary) 모델로만 나오며, QwenCloud API와 Qwen Studio·QwenWork·Qoder로 쓸 수 있다. 소형 Qwen4 모델의 오픈 공개는 약속했지만 시기·라이선스는 미정이고, Max의 가중치 공개 약속은 없다. 성능 평가는 복합적이다: 회사 차트는 일부 전문·장기 작업 벤치마크에서 경쟁력을 보이지만, 독립 종합 평가(Artificial Analysis)에서는 미국 선두 모델들과 문샷의 Kimi K3.1 Pro에 뒤진다고 VentureBeat은 전했다.

### 논조·다른 시각

- **기사 논조:** 혼재 — 비용 이점과 성능 한계를 균형 있게 다뤘다.
- **논조 점검:** 62% 비용 절감과 Work360 점수는 회사 자체 평가다. 토큰 단가가 작업당 비용을 결정하지 않는다는 점을 기사도 지적한다.
- **다른 시각:** 오픈웨이트로 성장한 Qwen 브랜드가 플래그십을 닫은 것은 전략 변화다. 기업 매출이 오픈 생태계보다 우선이라는 신호이자, 중국 모델의 수익화 압박을 보여준다.

**시사점:** '가장 똑똑한 모델'이 아니라 '충분히 똑똑하고 훨씬 싼 모델'의 공세다. GPT-6.2의 20% 인하(1번)와 같은 날 나온 뉴스라, 가격 경쟁이 본격화하는 신호다.
