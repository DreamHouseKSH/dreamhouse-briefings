### 요약

11-13 판에서 참고 보충으로 전한 llama.cpp v1.0.0의 실제 릴리스 시각이 11월 13일 19시 20분 KST로 확인됐다. 이후 나온 후속 보도의 공통 주제는 호환성이다. ComputingForGeeks는 제거된 공개 API 35개를 쓰던 연동 코드가 그대로는 동작하지 않는 절단 변경을 실제로 짚었고, RohitAI는 이 인터페이스에 의존하는 로컬 AI 앱들이 수정을 요구받는다고 정리했다. daily.dev는 이번 버전부터 시맨틱 버전(major.minor.patch 번호로 호환성을 알리는 규칙) 관리가 시작된 점을 짚었다.

기능 요약은 11-13 판과 같다: NextN·추측(speculative) API의 llama.h 정식 승격, OCP FP8 KV 캐시, 호스트 메모리 MoE 전문가 캐시, 서버 보안 강화(SSRF·CORS·DNS 리바인딩 방어와 MCP 도구 취소), OpenAI 호환 음성 합성 엔드포인트, 새 웹 UI. Hacker News 토론에서는 첫 메이저 버전의 의미와 제거 API 목록이 주로 다뤄졌다. 본 브리핑은 설치·성능 시험을 하지 않았다.

### 논조·다른 시각

- **기사 논조:** 긍정 속 경고 — 메이저 버전의 의미를 인정하면서 절단 변경을 강조한다.
- **논조 점검:** 후속 보도는 릴리스 노트 요약이 대부분이며 독립 성능 측정은 아직 적다. v1.0.0이라는 번호가 모든 환경의 안정성을 뜻하지 않는다.
- **다른 시각:** RohitAI와 ComputingForGeeks는 호환성 영향을, Hacker News 토론은 실사용자의 이전 경험을 담았다. ggml도 함께 v1.0.0으로 올랐다.

**시사점:** 로컬 추론 스택을 올리는 시점이라면 제거된 35개 API 사용 여부부터 확인하고, 서버를 외부에 열어 둔 경우 이번 보안 강화 목록이 적용 이유가 된다.
