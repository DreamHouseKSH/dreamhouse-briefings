### 요약

OpenAI가 GPT-6.1 Terra를 ChatGPT Work·Codex와 API(Application Programming Interface, 프로그램끼리 기능을 주고받는 창구)에 출시했다. 이미지를 읽고 화면을 조작하는 작업, 문서 작성에 초점을 둔 모델이다. API 식별자는 `gpt-6.1-terra`이며, 기존 제품의 기능 추가가 아니라 새 모델 공개다.

표준 API 가격은 100만 토큰(token, 모델이 글을 처리하는 조각)당 입력 1달러, 출력 5달러, 캐시(cache, 이전 입력을 저장해 다시 쓰는 방식) 입력 0.05달러다. OpenAI는 GPT-6.1 Sol과 GPT-5.6 Terra 대비 표준 가격이 50% 낮다고 설명한다. 다만 토큰 단가는 업무 전체 비용과 다르므로 실제 사용량과 도구 비용을 함께 봐야 한다. [모델 사양·요금 조건](https://developers.openai.com/api/docs/models/gpt-6.1-terra)

OpenAI 자체 평가에서는 컴퓨터 업무 수행 시간이 Astra·Sol보다 3배 이상 빨랐다. 이 수치를 모든 작업의 속도 보장으로 읽어서는 안 된다. 독립 평가기관 Artificial Analysis도 비용효율 개선을 확인했지만, 최대 추론 강도(reasoning effort, 답을 내기 위해 모델이 들이는 계산 노력)에서 종합 평가 점수는 GPT-6.1 Sol보다 4점 낮다고 보고했다. [독립 평가 원문](https://artificialanalysis.ai/articles/gpt-6-1-terra-pushes-the-cost-efficiency-frontier)
