### 해석

Nadella는 GitHub Universe 발표를 소개하며 소프트웨어 개발 전 과정이 에이전트 중심으로 바뀐다는 메시지를 냈다. 인용 보도에서 강조한 항목은 작업에 맞게 모델을 조합하는 Copilot Fusion, 여러 저장소의 에이전트 작업을 묶는 Copilot Projects, 그리고 Microsoft Foundry에서 제공하는 실행 기반이다. 단순 코드 자동완성보다 작업을 배분하고 완료 결과를 검토하는 경험에 초점을 둔다.

제품의 구체적인 범위는 GitHub 공식 발표에서 확인했다. Projects는 여러 저장소의 작업을 병렬 세션으로 관리하고, 세션 연속성은 휴대전화·편집기·명령행·웹을 오가며 같은 클라우드 작업을 이어가게 한다. 공식 발표는 개발자가 방향을 정하고 배포 결과에 책임을 지며, 에이전트가 구현·검증을 담당하는 역할 구분을 제시한다. 이는 사람이 모든 단계를 직접 실행하지 않아도 된다는 뜻이지 검토 책임이 사라진다는 뜻은 아니다.

성능 수치는 섞어 읽으면 안 된다. 인용된 X 글의 ‘최대 77% 낮은 비용’과 공식 블로그의 ‘특정 벤치마크에서 절반의 비용·40% 적은 작업 시간’은 동일한 조건의 수치라고 확인되지 않았다. 이 브리핑은 어느 쪽도 모든 개발 작업의 절감률로 일반화하지 않는다. 실제 도입에서는 완료 품질, 검토 부담, 사용량 기반 비용을 함께 확인해야 한다.
