## 1. 앤트로픽, IPO 공모가 83달러 확정 — 예상 범위 상회, 오늘 밤 나스닥 'ANT' 거래 시작

### 요약

앤트로픽이 18일(현지시간) IPO 공모가를 주당 83달러로 확정했다고 CNBC가 소식통을 인용해 보도했다. 지난주 수정 투자설명서의 예상 범위(70~78달러)를 웃도는 가격이다. 19일(현지시간, 한국시간 19일 밤) 나스닥에서 티커 'ANT'로 거래를 시작한다. 당초 계획한 8억 2,500만 주가 모두 팔리면 조달액은 약 685억 달러로, 6월 SpaceX의 역대 최대 IPO(750억 달러, 그린슈 포함 857억)에 이은 초대형 딜이다. 공모가 기준 기업가치는 앞서 목표로 알려진 1.4조 달러를 넘어선다.

투자설명서 수치도 함께 주목된다. 2026년 1~9월 매출은 332억 4,000만 달러로 전년 동기 대비 약 1,200% 늘었고, 10월 말 기준 연환산(run-rate) 매출은 약 810억 달러로 한 달 새 100억 달러가 불었다. 같은 기간 순손실 1,040억 달러는 대부분 전환사채·파생상품 공정가치 변동에 따른 회계상 손실이다. 아마존과 구글은 각각 1,000억 달러가 넘는 지분을 보유 중이고, 구글·MS·엔비디아·AMD 등은 공모에 총 260억 달러를 공동 투자하기로 했다. OpenAI는 기밀 IPO 신청을 마쳤고 데뷔는 2027년이 유력하다고 CNBC는 전했다.

- **다른 시각:** 금리 상승으로 데이터센터 개발사·네오클라우드의 부채 부담이 커지는 국면에서 1.4조 달러 이상의 밸류에이션이 유지될지는 미지수라는 시각이 있다.

**시사점:** AI 산업 최대 규모급 상장의 첫날 성적표가 오늘 밤 나온다. 첫 거래 시초가와 종가 괴리는 앞으로 이어질 OpenAI 등 AI 기업 상장의 가격 기준점이 된다. 한국 시장에는 반도체 투심과 환율을 통해 즉시 연동된다.

## 2. Claude Code에 실험적 'Code Mode' — 도구 호출을 스크립트로 묶어 토큰 절감

- **원문:** https://trending.llmnet.nl/en/briefing/2026-11-18 (llmnet 브리핑, @ClaudeDevs 공식 계정 게시 인용)
- **분야:** AI · 개발 도구
- **최초 게시:** 2026-11-18 (llmnet 브리핑 수록분)
- **시간 판정:** 정규 구간 내 확인

### 요약

앤트로픽 Claude 개발자 계정이 Claude Code의 실험적 기능 'Code Mode'를 공개했다. 에이전트가 도구를 하나씩 순차 호출하는 대신, 도구 호출을 엮는 스크립트를 직접 작성해 실행하는 방식이다. 환경 변수 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`로 켠다. 다수의 MCP 서버를 연결해 쓰는 환경에서 토큰 사용량을 줄일 수 있다는 기대가 나오지만, llmnet 브리핑은 이 절감 효과가 "측정이 아니라 기대"라고 명시했다. 해당 문서 페이지(Run tool calls from code with Code Mode)는 브리핑 작성 시점에 열리지 않아 세부는 공식 게시 기준이다.

같은 계정은 '연결 과금(linked billing)' 베타도 발표했다. Factory, Linear, Ramp, Warp 등의 사용자가 API 키 공유 없이 자신의 Claude Platform 조직을 통해 Claude 사용료를 결제하는 구조다. Claude Desktop에는 안정판보다 수정이 빠른 대신 신뢰도가 낮은 'Latest' 릴리스 채널이 추가됐다.

### 논조·다른 시각

- **기사 논조:** 중립 — 기능 소개와 검증 수준(confidence: medium)을 함께 표기한 2차 브리핑이다.
- **논조 점검:** 공식 개발자 계정 발표라 실재성은 높지만, 문서 미확인 상태의 실험 기능이다. 토큰 절감 효과는 테스트 저장소에서 일반 실행과 비교해 볼 때까지 열어둬야 한다.
- **다른 시각:** 스크립트 기반 도구 연쇄는 에이전트가 더 긴 행동을 한 번의 실행으로 처리한다는 뜻이라, 잘못된 스크립트의 실패 범위도 커질 수 있다.

**시사점:** 상장을 하루 앞둔 앤트로픽이 수익 모델의 두 축, 개발자 도구(Claude Code)와 플랫폼 과금(연결 과금)을 동시에 다듬고 있다. Code Mode가 자리 잡으면 MCP 생태계의 사용 패턴이 '도구 나열'에서 '도구 합성'으로 이동할 수 있다.

## 3. Perplexity, 'Orchestrator API' 공개 — 수십 개 모델을 하나의 API로 자동 라우팅

- **원문:** https://trending.llmnet.nl/en/briefing/2026-11-18 (llmnet 브리핑, Perplexity 문서 확인 기준)
- **분야:** AI · 플랫폼/API
- **최초 게시:** 2026-11-18 (llmnet 브리핑 수록분)
- **시간 판정:** 정규 구간 내 확인

### 요약

Perplexity가 OpenAI, 앤트로픽, 구글, xAI와 오픈웨이트 제공사의 모델들을 하나의 API 뒤에 묶은 'Orchestrator API'를 출시했다. 가용성·용량·지연시간을 보고 제공사를 자동으로 골라주며, 통합 과금을 제공한다. llmnet이 직접 확인한 문서 기준으로, OpenAI Chat Completions·Responses와 Anthropic Messages 형식을 모두 지원하고, 요청 모델의 토큰 요율 그대로 과금하며 건당 추가 요금은 없다. 실패한 요청은 같은 모델의 다른 배포로 재전송한다. 자체 제공사 키(BYOK)는 받지 않고 일부 모델은 상위 사용 등급이 필요하다. 공식 게시는 45개 이상 모델과 키별 지출 한도를 언급했지만 문서상 총 모델 수와 지출 한도는 확인되지 않았다고 브리핑은 덧붙였다.

한편 아라빈드 스리니바스 CEO는 연간 매출(ARR)이 10억 달러를 넘었다고 밝혔다. Perplexity는 Computer와 Teammates에 'Multiagent' effort 레벨도 추가했다.

### 논조·다른 시각

- **기사 논조:** 중립~긍정 — 문서 확인 부분과 미확인 부분을 구분해 신뢰도를 표기했다.
- **논조 점검:** 라우팅 품질과 '자동 선택' 단계의 비용이 별도로 설명되지 않는다는 점은 짚고 넘어갈 대목이다. BYOK 불가는 기존 키로 요금을 최적화하던 팀에는 제약이다.
- **다른 시각:** 모델 게이트웨이는 OpenRouter 등 선발 주자가 있는 시장이다. Perplexity의 차별점은 검색·에이전트 제품군과의 묶음이다.

**시사점:** '모델 하나에 올인'이 아니라 '작업마다 모델을 고른다'가 플랫폼 기본값으로 자리 잡는 흐름이다. OpenAI·앤트로픽이 상장 시장으로, 구글이 모델로 치고 나오는 사이 Perplexity는 중간 계층의 게이트웨이 자리를 노린다.
