## 2. Llama Chat, npm 패키지로 — `npx @ggml-org/llama-chat` 한 줄이면 웹 UI 기동

- **원문:** https://ai-eng-digest.astgl.ai/sections/local.html (AI Engineering Digest 2026-11-18판, llama.cpp PR #32524·#32527)
- **분야:** 엔진 · 로컬 추론/UI
- **최초 게시:** AI Engineering Digest 2026-11-18판 (머지 일시 11-18 06:58 ET)
- **시간 판정:** 정규 구간 내 확인

### 요약

llama.cpp의 웹 UI인 Llama Chat이 npm 패키지로 배포되기 시작했다(PR #32524, 18일 머지). `npx @ggml-org/llama-chat` 한 줄이면 로컬호스트에 웹 UI가 뜨고, `npx llama-chat build`는 정적 파일로 뽑아준다. 구조는 단순하다. CLI는 정적 파일만 서빙하고, 브라우저가 각 llama-server와 직접 통신한다. 따라서 `--cors-origins`와 `--api-key` 같은 서버 측 설정은 여전히 필요하다.

주의할 점이 하나 있다. npm 퍼블리시에는 trusted-publisher 설정이 선행돼야 해서, 다이제스트 확인 시점에는 패키지가 아직 레지스트리에 안 올라왔을 수 있다는 단서가 붙어 있다. 함께 머지된 #32527은 UI에서 Models와 MCP 메뉴를 설정 뒤로 숨기고 기본값을 꺼둔 상태로 바꿨다.

### 논조·다른 시각

- **기사 논조:** 중립 — 배포 방식 변경 정리다.
- **논조 점검:** 'npm으로 배포'는 다운로드 경로의 변화이지 기능 추가가 아니다. 다만 Node 생태계 사용자에게 진입 장벽을 크게 낮추는 변화다.
- **다른 시각:** 브라우저-서버 직결 구조는 서버가 여러 대일 때 유연하지만, 인증 설정을 빠뜨리면 로컬 네트워크에 노출될 수 있다.

**시사점:** 로컬 LLM 도구의 설치 경험이 '클론 후 빌드'에서 'npx 한 줄'로 수렴하고 있다. Ollama가 닦아놓은 '설치 없이 시작' 기대치에 llama.cpp 진영이 응답한 셈이다.

## 3. llama.cpp에 Hy4 flash 지원 PR — 텐센트 신모델 출시와 동시에, SGLang v1.0 보도도

- **분야:** 엔진 · 추론 프레임워크
- **최초 게시:** AI Engineering Digest 2026-11-18판 (PR 오픈 11-18 00:20 ET)
- **시간 판정:** 정규 구간 내 확인

### 요약

텐센트 Hy4 flash 공개(모델 브리핑 2번)와 같은 날, llama.cpp에 `hy_v4_flash` 지원 PR(#32517)이 드래프트로 올라왔다. 텍스트와 비전을 모두 다루며, 하이브리드 스파스/슬라이딩 윈도 어텐션, 압축 k-풀 인덱서, Engram n-그램 해시 임베딩, 잠재공간 전문가, MTP 드래프트 블록을 구현한다. 텐센트의 GGUF README가 이 브랜치를 안내한다. 전날에는 시퀀스 편집 시 k-풀 레이아웃 접두사를 유지하는 #32137이 머지됐다.

한편 SGLang은 v1.0 출시와 함께 NVIDIA, AMD, Intel, Google, Meta, Thinking Machines, Cloudflare, Modal, RadixArk 등이 창립 멤버로 이름을 올린 'SGLang Consortium' 소식이 보도됐다. llmnet 브리핑은 이 항목을 "1차 출처 미확인(confidence low-medium)"으로 표기했으므로 창립 멤버 명단은 프로젝트 공식 발표를 확인해야 한다. 현재 SGLang의 태그 릴리스는 v0.5.23, Ollama는 안정판 0.40.16(11-09)과 v0.40.17-rc1(11-10) 상태다.

### 논조·다른 시각

- **기사 논조:** 중립 — PR 현황과 보도 신뢰도 표기다.
- **논조 점검:** #32517은 드래프트이므로 실사용은 머지 이후다. SGLang v1.0·컨소시엄은 확인된 1차 출처가 없어 보류 표시가 맞다.
- **다른 시각:** 신모델 공개일에 런타임 지원 PR이 동시에 열리는 패턴(Qwen·DeepSeek에 이어 Hy4까지)은 모델사와 로컬 런타임의 사전 협업이 일상화됐음을 보여준다.

**시사점:** 로컬 추론 엔진의 경쟁력은 '최신 모델을 얼마나 빨리 돌리느냐'로 측정되는 시대다. SGLang 컨소시엄이 사실이라면 추론 엔진이 특정 벤더 프로젝트를 넘어 업계 공동 인프라로 격상되는 신호다.
