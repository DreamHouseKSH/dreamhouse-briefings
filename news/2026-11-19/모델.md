## 1. 구글, Gemini 4 Neon 공개 — "프론티어급 지능 + 빠른 완결", 입력 $3·출력 $15

- **원문:** https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/ (구글 공식 블로그)
- **분야:** 모델 · 구글 DeepMind
- **최초 게시:** 구글 블로그 2026-11-18
- **시간 판정:** 정규 구간 내 확인

### 요약

구글이 18일 Gemini 4 Neon을 발표했다. "복잡한 소프트웨어 엔지니어링·지식노동·과학 워크플로를 빠르게 끝까지 완결하는 프론티어급 지능"이 표어다. 가격은 입력 100만 토큰당 3달러(캐시 입력 0.15달러, 95% 할인), 출력 100만 토큰당 15달러이며 컨텍스트 창은 100만 토큰이다. 당일부터 Gemini API(AI Studio), Gemini for business, Antigravity(Pro·Ultra 구독자), Gemini 앱(Pro·Ultra)에 순차 배포된다.

벤치마크 수치(구글 인용 기준)는 이렇다. Artificial Analysis Intelligence Index에서 xhigh 사고 수준 기준 61점으로 전체 3위 — 더 크고 느린 모델들 바로 뒤다. Vals Index 2위(70.9%)로 파레토 프론티어에 올랐고, Legal Research Bench와 Tax Agent Bench는 1위다. 코딩은 Artificial Analysis Coding Agent Index 1위(58.6), Terminal-Bench 4.1 65.2%, SWE-sweep에서 Antigravity 하니스(harness, 에이전트 실행 환경)와 결합 시 39.0%로 단독 실행(12.8%)의 3배다. 과학·수학은 Terminal-Bench Science 70.5%, RiemannBench 84.0%, HLE-Diamond 71.3%로 구글 자체 최고를 표방한다. 에이전트 조작성은 새 Agent Arena Index에서 조종성(steerability) 2위, 전체 2위(1336점, 실사용 세션 4,200건 이상)이며 "역대 최저 날조율"을 기록했다고 밝혔다. 사고 수준은 4단계로 세분화해 토큰 지출을 조절할 수 있다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 자사 신모델 발표 형식의 공식 블로그다.
- **논조 점검:** 벤치마크 대부분이 구글 인용 수치이고, 일부 지표(SWE-sweep 39.0%)는 자사 하니스(Antigravity) 결합 조건이라 독립 환경 재현이 필요하다. '역대 최저 날조율'은 자사 Antigravity 내부 테스트 기준이다.
- **다른 시각:** 가격(입력 $3·출력 $15)은 전날 공개된 OpenAI GPT-6.2 Astra($8/$40)와 Sol($2/$10)의 정중간에 위치한다. 3사 플래그십의 가격-성능 경쟁이 같은 주에 동시에 벌어진 셈이다.

**시사점:** Neon은 '최고 지능'이 아니라 '프론티어 직하의 가성비 완결형' 포지셔닝이다. Gemini 4 패밀리(Carbon·Hydrogen·Argon·Neon)의 라인업 전개가 빨라지면서, 구글은 모델 하나의 왕좌보다 계층별 포트폴리오로 승부하는 전략을 분명히 했다.

## 2. 텐센트, Hy4 flash 오픈소스 — 224B 스파스 모델, 활성화는 12B뿐

- **원문:** https://news.aibase.com/daily/32384 (AiBase 데일리) · https://ai-eng-digest.astgl.ai/sections/local.html (AI Engineering Digest, llama.cpp 지원 PR 확인)
- **분야:** 모델 · 오픈소스
- **최초 게시:** AiBase 2026-11-18
- **시간 판정:** 정규 구간 내 확인

### 요약

텐센트 훈위안(Hunyuan)이 224B 파라미터 대형 모델 'Hy4 flash'를 오픈소스로 공개했다. 스파스(sparse) 아키텍처로 추론 시 활성화되는 파라미터는 12B에 불과하고, 100만 토큰 컨텍스트를 지원한다. Standard·FP8·Base 세 버전의 가중치가 4개 플랫폼에 공개됐고 GitHub에서도 받을 수 있다. API 가격도 함께 인하했다. 텐센트 클라우드 TokenHub, 위안바오(Yuanbao) 등 자사 제품에 이미 통합됐고, 더 큰 모델의 프리뷰도 예고됐다.

구조적으로는 하이브리드 스파스/슬라이딩 윈도 어텐션에 압축 k-풀 인덱서, Engram n-그램 해시 임베딩, 잠재공간 전문가(latent-space experts), MTP 드래프트 블록을 얹은 설계다. 오픈소스 생태계 반응은 빠르다. llama.cpp에는 이미 `hy_v4_flash`(텍스트·비전) 지원 PR(#32517)이 드래프트로 올라와 있고, 텐센트의 GGUF README가 이 브랜치를 가리킨다(엔진 브리핑 3번 참조).

### 논조·다른 시각

- **기사 논조:** 긍정 — "가성비 각도로 오픈소스 진입"이라는 평가가 붙은 중국 AI 매체의 정리다.
- **논조 점검:** 224B/12B 활성화·100만 컨텍스트는 공개 스펙이지만, 독립 벤치마크는 아직 나오지 않았다. 대형 중국 오픈모델(Qwen·DeepSeek 계열)과의 실측 비교가 나와야 위치가 잡힌다.
- **다른 시각:** llama.cpp 지원이 드래프트 단계라는 점은 로컬 실행 생태계가 사실상 출시와 동시에 움직였다는 뜻이자, 아직 검증이 덜 끝났다는 뜻이기도 하다.

**시사점:** 오픈웨이트 대형 모델의 경쟁 축이 '총 파라미터'에서 '활성화 파라미터 대비 성능'으로 이동하고 있다. 12B 활성화로 100만 컨텍스트를 돌린다면 고사양 로컬 환경과 중소 규모 서버의 선택지가 넓어진다.

## 3. 구글, Genie 4를 Project Genie에 투입 — 프롬프트로 실시간 편집되는 월드 모델

- **원문:** https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/ (구글 공식 블로그)
- **분야:** 모델 · 월드 모델/생성형 인터랙티브
- **최초 게시:** 구글 블로그 2026-11-18
- **시간 판정:** 정규 구간 내 확인

### 요약

구글이 인터랙티브 월드 생성 실험 프로젝트 'Project Genie'의 새 버전을 Google AI Ultra 구독자에게 배포했다. 핵심은 최신 월드 모델 Genie 4의 첫 공개다. 탐험 도중 새 프롬프트를 입력해 세계를 실시간으로 편집할 수 있고(날씨 변경, 캐릭터 투입, 동선 수정), 처음으로 장면 전개에 맞춰 변하는 네이티브 실시간 오디오(환경음·대사)가 붙는다.

Genie 3도 동시 업그레이드됐다. 생성 시간이 60초에서 최대 3분으로 늘고 여러 세계를 연결하는 월드 체이닝, 360도 파노라마 이미지 기반 시딩, 탐험 중 자연어 실시간 이벤트가 추가됐다. 'Project Genie 에이전트'는 자연어 대화만으로 구글의 멀티모달 모델들을 오케스트레이션해 초기 비주얼과 배경 음악까지 만든다. 커뮤니티 갤러리도 열려 세계를 공유·리믹스할 수 있다. 모든 생성 영상·오디오에는 SynthID 워터마크가 들어가고 입출력 안전 심사를 거친다. 구글은 카메라 지연, 물리 상호작용, 장면 영속성을 남은 과제로 명시했다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 자사 제품 업데이트 발표다.
- **논조 점검:** Ultra 구독자 한정(Pro는 대기자 명단)이라 실사용 검증은 소수에 국한된다. Genie 3·4 모두 "프론티어 연구 단계"라는 구글 스스로의 단서가 붙어 있다.
- **다른 시각:** 월드 모델은 게임·시뮬레이션·로봇 학습 데이터 생성 등으로 쓸모가 갈리는 기술이라, '놀이' 이상의 생산성 적용은 아직 초기라는 평가가 있다.

**시사점:** 텍스트→영상 생성의 다음 개척지는 '살아 있는 공간'이다. Genie 4의 실시간 편집·네이티브 오디오는 월드 모델이 프레젠테이션 데모를 넘어 인터랙티브 매체로 넘어가는 분기점으로 읽힌다. Ultra 구독 묶음으로 수익화 동선도 분명해졌다.
