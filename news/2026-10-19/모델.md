## 1. DeepSeek V4.1 Flash 1017 — 마이너 업데이트지만 Code Arena 오픈 1위

- **원문:** https://cryptobriefing.com/deepseek-v4-1-flash-tops-code-arena/
- **분야:** 모델 · 오픈 가중치
- **날짜:** 2026-10-18

### 요약

DeepSeek가 10월 17일 V4.1-Flash의 업데이트 버전인 DeepSeek-V4.1-Flash-1017을 공개했다. 9월 10일 나온 V4.1 Flash의 마이너 업데이트로, 회사 설명에 따르면 추론·코딩·에이전트·비전 성능이 오르고 작업 완료는 빨라지며 출력 토큰은 줄었다. 가중치는 Hugging Face와 ModelScope에 MIT(매사추세츠 공과대학의 관대한 오픈소스 라이선스) 라이선스로 공개됐고, DeepSeek 웹·앱·API의 모든 Flash 트래픽이 이 버전으로 서비스된다.

수치는 전부 회사 발표 기준이다. DeepSWE v1.1 77.0(이전 74.2), Terminal-Bench 4.0 42.3(이전 31.2), Automation-Bench 60.5(이전 54.8), Agents' Last Exam 35.4(이전 31.8), 도구 없는 HLE(Humanity's Last Exam, 인류 최후의 시험 — 어려운 종합 추론 능력을 재는 벤치마크) 42.6(이전 36.8) 등 회사 공개 11개 지표가 모두 올랐다. 구조는 552B(백본)+196B Engram 파라미터의 MoE(Mixture of Experts, 전문가 혼합 — 토큰마다 일부 하위 네트워크(전문가)만 깨워 계산하는 구조)로, 입력 처리(prefill — 모델이 프롬프트를 읽고 이해하는 추론의 전반부) 시 8B, 생성(decoding — 모델이 토큰을 하나씩 써내는 추론의 후반부) 시 16B만 활성화한다. 컨텍스트(Context — 모델이 한 번에 볼 수 있는 입력 길이) 100만 토큰, 가격(피크)은 입력 100만 토큰당 0.30달러·출력 1.20달러다.

주목할 점은 10월 18일 Arena.ai가 Code Arena WebDev 리더보드에서 이 빌드를 오픈 모델 1위(전체 12위, 1670점)에 올린 것이다. 기존 1위 Kimi K3 (Max)를 밀어냈고, Arena.ai는 비용이 약 1/10 수준이라고 밝혔다. 같은 날 DeepSeek는 웹 검색·페이지 수집 API(Search and Fetch, 1,000콜당 0.75달러)도 내놨고, DeepSeek Harness·Claude Code·Codex 연동 사용자에게는 10월 31일까지 무료로 제공한다.

## 2. Kling 4.0 — 한 번에 30초 생성하는 중국발 비디오 모델 (글로벌 출시 발표 10/16)

- **원문:** https://aiparabellum.com/kling-4-ai-video-model/
- **분야:** 모델 · 비디오 생성
- **날짜:** 2026-10-16
- **심층 리서치:** [Kling 4.0 — '한 번에 30초'를 넘어 '연출'로 가는 비디오 모델](../../research/2026-10-21-kling-4-0-video-model.md)

### 요약

콰이서우(快手) 산하 Kling AI가 비디오 생성 모델 Kling 4.0의 글로벌 출시를 10월 16일 발표했다. (발표일이 10월 15~16일로 24시간 창보다 하루 앞선다.) 핵심은 한 번에 최대 30초 분량을 생성한다는 점으로, 전작 Kling 3.0(15초)의 2배이며 Google Veo 3.1의 기본 8초 대비 약 4배다. 회사 설명에 따르면 빠른 움직임과 복잡한 카메라 경로(주체 추적·오빗 샷)에서의 연속성이 개선됐고, 최대 15개의 멀티모달 레퍼런스(기존 7개·이미지/영상/캐릭터/음성)와 최대 10개의 키프레임을 지원한다. 단 멀티 레퍼런스 모드와 키프레임 모드는 한 작업에 혼용할 수 없다. 오디오는 스테레오로, 색상은 10-bit HDR(High Dynamic Range, 명암 표현 폭이 넓은 색상 규격)까지 지원한다.

롤아웃은 2단계다. 가벼운 Kling 4.0 Flash는 9월 28일부터 Ultra Yearly 구독자에게 조기 접근으로 720p·20초를 제공하고, 풀 모델이 10월 15일 공개됐다. 4K와 1080p의 10-bit HDR, 2분까지의 클립 연장은 "곧 출시"로 표시돼 현재 생성 불가다. 출시 노트에는 MCP(Model Context Protocol, AI가 외부 도구·데이터에 붙는 표준 규격)와 커맨드라인 도구 지원도 언급돼 에이전트 워크플로우 편입을 노린다.

회사는 사용자 1억 명 이상·224개국, 기업 고객 5만 곳, 연간 매출 약 5억 달러(회사 발표)를 주장한다. 부산국제영화제 연계 패널에서는 김성수 감독이 AI 단편 '웜 트레인' 제작에 Kling 4.0을 쓴 사례가 소개됐다. 발표 다음 날인 10월 16일 콰이서우 주가는 3.99% 올랐고, 홍콩 IPO(Initial Public Offering, 기업공개 — 주식시장에 처음 상장)(2027년·최소 10억 달러 목표) 보도도 함께 돌았다.

- **기사 논조:** 긍정적이나 신중 — aiparabellum은 "출시 포스트는 증거가 아니다. 작은 테스트부터"라는 실무 조언을 덧붙인다.
