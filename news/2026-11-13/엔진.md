### 요약

정규 구간 안에서 확인된 엔진 릴리스는 없었고, 구간 직후에 나온 주요 릴리스 1건을 보충한다. llama.cpp가 b번호 시대를 마감하고 첫 v1.0.0을 냈다. 사용 중단 예정이던 공개 API 35개를 제거하고 NextN/추측(speculative) API를 llama.h 정식으로 승격시켰다. 기존 연동 코드가 있다면 제거된 API 사용 여부부터 확인해야 한다.

기능 면에서는 OCP FP8 KV 캐시(f8_e4m3), CPU 비중을 설정할 수 있는 호스트 메모리 MoE 전문가 캐시(캐시된 전문가는 CPU 대기 없음), 외부 PLE 샤드 로딩이 추가됐다. 새 아키텍처로 Kimi-K3.1-Pro, Ripple-65B, xing4_0을 지원하고 drama-3 TTS와 MageVL-Cowork·Kimi-K3.1의 비전 입력이 들어왔다. llama-server는 SSRF·CORS·DNS 리바인딩 방어와 MCP 도구 취소로 보안을 강화했고 OpenAI 호환 /v1/audio/speech 엔드포인트와 재설계된 웹 UI(채팅 그룹·마크다운 편집기)를 갖췄다. ggml도 v1.0.0으로 함께 올랐다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 메이저 버전다운 정리와 기능 추가다.
- **논조 점검:** 릴리스 노트의 자체 요약이며 설치·성능 재현 시험은 하지 않았다. v1.0.0이라는 번호가 모든 환경의 안정성을 뜻하지는 않는다.
- **다른 시각:** 독립 반론은 확보하지 못했다(검색 범위: 공식 릴리스와 Hugging Face 공식 블로그).

**시사점:** 로컬 추론 스택을 llama.cpp 위에 둔 사용자는 업그레이드 전 제거된 API 사용 여부와 서버 보안 설정을 점검할 시점이다.
