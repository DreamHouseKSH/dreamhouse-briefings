## 1. Google, Gemini 4 Hydrogen 공개 — 에이전트 실행형, 100만 토큰 전 구간 균일 가격

- **원문:** https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/
- **분야:** 모델 · 신규 모델 / API
- **날짜:** 공식 2026-11-12 (11-13 업데이트 표기)
- **시간 판정:** 정규 구간 내(날짜 기준)

### 요약

Google이 Gemini 4 제품군의 고속 실행형 모델 Hydrogen을 공개했다. 프론티어 모델 Carbon과 Argon이 긴 추론을 맡는 사이, Hydrogen은 코딩과 에이전트 작업의 빠른 실행을 겨냥한다. 가격은 입력 100만 토큰당 1.50달러, 출력 100만 토큰당 7.50달러로 100만 토큰 문맥 전 구간에서 균일하다.

회사 자체 측정에서 Hydrogen은 Artificial Analysis Intelligence Index 기본 high 사고 수준 51점으로 Argon(50)을 앞섰고(xhigh 설정 54), Gemini 3.8 Flash 대비 작업 완료가 2.5배 빠르고 Terminal-Bench 4.1 점수는 57% 대 18.2%로 세 배 이상이며 날조 주장은 5배 이상 줄었다고 한다. 입력 100만 토큰, 출력 최대 100만 토큰을 지원하고 AI Studio·Gemini API·비즈니스·앱·Search·유료 Antigravity 구독자에게 제공된다. Antigravity의 Orchestrator는 한 세션 안에서 Carbon과 Hydrogen을 자동 전환하며, Terminal-Bench 4.0에서 Carbon에 근접한 성공률을 쿼터 24% 절감·19% 단축으로 달성했다는 설명이다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 속도·가격·벤치마크 개선을 강조하는 출시 발표다.
- **논조 점검:** 벤치마크와 파트너 초기 시험(2~2.8배 빠른 실행, 토큰 12~23% 절감)은 모두 회사 자체 측정이며 독립 재현이 아니다. Search 적용이 모든 질의의 즉시 동일 적용을 뜻하는지는 원문만으로 확인되지 않았다.
- **다른 시각:** 독립 반론은 확보하지 못했다(검색 범위: Gemini 4 Hydrogen 출시, The Neuron·AI Atlas 등 11-12 AI 다이제스트).

**시사점:** 프론티어 판단과 고속 실행의 멀티모델 분업이 공식 제품 구조가 됐다. 실제 배치는 자기 작업 기준의 지연·비용·성공률 시험 후에 결정하는 편이 맞다.

## 2. Baidu, ERNIE 5.5 Flash Preview — 280B/14B 활성 MoE, 가중치 Apache 2.0 공개 예고

- **원문:** https://ernie.baidu.com/release/ernie-5-5-flash-preview/
- **분야:** 모델 · 신규 모델 (사전판)
- **날짜:** 공식 2026-11-11, 시각 미표시
- **시간 판정:** 시간 미확인 참고 보충

### 요약

Baidu가 앞서 공개한 ERNIE 5.5 Flash Base 위에 후학습한 첫 모델이다. 총 280B 파라미터에 토큰당 14B만 활성화하는 MoE(Mixture-of-Experts, 전문가 조합) 구조이고, 100만 토큰 문맥을 지원한다. 코딩·3D 모델링·지식 업무·콘텐츠 제작에 강점을 주장하며, API는 Qianfan 플랫폼에서 이용할 수 있다.

가중치는 "곧" Apache 2.0으로 오픈소스화한다는 예고이며 공개 완료가 아니다. 회사 시연에는 Unreal Engine 5.8에서 11시간 연속 작업으로 무협 게임 전체를 C++로 작성한 사례와 약 100개의 모바일 미니게임 제작이 포함됐다. 텍스트 전용 모델이라 화면을 보지 못해 플레이테스트 피드백을 코드 테스트로 바꿔 반복했다는 설명이다.

### 논조·다른 시각

- **기사 논조:** 긍정 — 회사 시연과 자체 벤치마크 중심이다.
- **논조 점검:** Preview 단계이며 독립 벤치마크 재현이 없다. 가중치 공개 시점과 최종 라이선스 조건은 실제 공개 때 다시 확인해야 한다.
- **다른 시각:** 독립 반론은 확보하지 못했다(검색 범위: ERNIE 5.5 Flash Preview 공식 발표와 11-12 AI 다이제스트).

**시사점:** 오픈 가중치 진영의 대형 MoE 선택지가 늘어나는 흐름이다. Apache 2.0 공개가 실현되면 자체 호스팅 후보가 되지만, Preview의 시연 성능과 실서비스 품질은 별개다.
