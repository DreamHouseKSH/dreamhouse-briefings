## 1. Anthropic 'Claude Ship' 시험 — 정책 파일이 허용하면 AI가 루틴 코드 변경을 승인

- **원문:** https://realpython.com/ai-news-weekly-2026-11-27/ (Real Python, Anthropic 공지 요약)
- **분야:** AI · 개발 도구
- **최초 게시:** Real Python 2026-11-27 (Anthropic 공지 시각 미확인)
- **시간 판정:** 구간 경계(주간 뉴스 발행일 기준)

### 요약

Anthropic이 풀 리퀘스트(변경 제안) 검토를 맡는 도구 묶음을 시험 중이다. Code Review는 이미 정식이고, PR Steward는 실패한 검사를 고치고 피드백에 답하되 절대 승인하지 않게 설계됐다. Claude Approvals는 팀이 쓴 정책 파일을 따르며 정책이 허용하면 사람 없이 루틴 변경을 승인할 수 있다. Claude Code에는 변경 전송·PR 생성·검토 대응을 이어 처리하는 `/ship` 명령이 붙는다. Anthropic은 자사 Claude Code 팀의 병합 PR이 6~9월 사이 두 배 넘게 늘고 되돌린 비율은 40% 넘게 줄었다고 밝혔다. PR Steward와 Approvals는 베타이며 Team·Enterprise 요금제, GitHub 코드에 한한다.

### 논조·다른 시각

- **기사 논조:** 설명형이며 '승인의 책임은 각 회사의 선택'이라는 점을 강조한다.
- **논조 점검:** 생산성 수치는 Anthropic 자사 측정이다. Anthropic도 도구가 버그·보안 허점을 놓칠 수 있다며 감시 전용 모드부터 시작하라고 권한다.
- **다른 시각:** 사람이 승인 책임을 지던 마지막 단계를 정책 파일이 대신하게 되는 점을 위험으로 보는 시각이 가능하다.

**시사점:** 11-27 판의 Anthropic Messages API Rust 이전에 이어, 자사 개발 방식을 제품으로 내놓는 흐름이다. 11-23 판 Hermes '승인 카드'와 같은 주제의 반대편 선택지다.

### 논조·다른 시각

- **기사 논조:** 요약형 — 각 항목을 한두 문장으로 압축했다.
- **논조 점검:** 아직 발언 원문과 OpenRouter 원 데이터를 직접 확인하지 못한 집계 매체의 요약이다. '5~20%'는 마이크로소프트 측 주장이다.
- **다른 시각:** '뒤처지지만 싸다'는 프레임은 자사 모델의 열세를 비용 우위로 바꿔 말하는 전형적 포지셔닝이라는 읽기도 있다.

**시사점:** 11-24 판 GLM-5.4의 '루프 트랜스포머'(적은 파라미터로 더 많은 사고)와 함께, 이번 주 '성능이 아니라 단가' 논의가 늘고 있음을 보여 준다.
