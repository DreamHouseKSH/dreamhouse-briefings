## 1. Anthropic Claude Haiku 5.5 — Haiku 4.5보다 약 75% 싸고 훨씬 똑똑한 소형 모델

- **원문:** https://www.anthropic.com/claude-haiku-5-5
- **분야:** 모델 · 상용 API
- **날짜:** 2026-10-07

### 미디어

![Claude Haiku 5.5 소개 이미지 (Anthropic)](https://www-cdn.anthropic.com/images/4zrzovbb/website/89e9b0fbfe0181f6ca565d913686ce8e49b5e9c2-1200x630.jpg)

> 출처: 원문 페이지 (Anthropic) — 원본 이미지 링크(복제 저장 아님)

### 요약

Anthropic이 Claude 5.5 제품군의 세 번째이자 가장 작은 모델 **Claude Haiku 5.5**(`claude-haiku-5-5`)를 출시했습니다. 요약, **컴팩션(compaction, 긴 대화 기록을 압축)**, DB 조회, 분류 같은 대량·반복 작업과, Opus 5.5·Sonnet 5.5가 코딩할 때 옆에서 일을 나눠 받는 **서브에이전트(subagent)**, 실시간 고객 상담·브라우저 사용처럼 속도가 중요한 작업을 겨냥합니다. 1M 토큰 **컨텍스트 창(context window, 한 번에 넣을 수 있는 입력 길이)**, 최대 128k 출력, Haiku 급 최초의 **effort(추론 노력 조절) 설정** 을 지원합니다.

가격은 100만 토큰당 입력 0.10달러·출력 0.50달러(프롬프트 10만 토큰 이하), 10만 토큰 초과 시 0.50·2.50달러입니다. Haiku 4.5(입력 1달러·출력 5달러)보다 짧은 요청은 90%, 긴 요청은 50% 싸며, 새 **토크나이저(tokenizer, 글을 토큰으로 쪼개는 규칙)** 로 토큰을 조금 더 쓰는 점까지 감안하면 평균 약 75% 저렴하다는 게 회사 설명입니다(Haiku 4.5 요청의 90%가 10만 토큰 이하).

회사 발표 벤치마크로는 컴퓨터 조작 **OSWorld 2.1**(오프라인 부분집합) 72.4%(Haiku 4.5는 15.7%, GPT-6 Luna 48.9%), 터미널 코딩 **Terminal-Bench 4.0** 39.2%(Haiku 4.5 0.0%, Sonnet 5.5 70.6%), **Humanity's Last Exam**(전문가급 종합 추론) 도구 없이 45.9%, 지식 업무 GDPval-AA v2.1 1620점(GPT-6 Luna 1437) 등입니다. Anthropic은 복잡한 에이전트 코딩은 여전히 Sonnet·Opus가 낫고, Haiku 5.5는 좁은 범위의 대량 작업용이라고 선을 그었습니다. 로이터는 고위험 사이버보안 요청에 대한 안전장치를 내장한 첫 Haiku라고 전했습니다. Claude API, AWS Bedrock, Google Cloud, Microsoft Foundry 등에서 바로 쓸 수 있습니다.

**시사점:** "싸고 빠른 서브에이전트" 자리에 성능이 크게 오른 선택지가 생겼습니다. 같은 날 발표된 Sonnet 캐시 인하(AI 브리핑 3번)와 함께 에이전트 운영비를 줄이는 쪽으로 무게가 실렸습니다.

## 2. Liquid AI 'Open d1' — 토큰을 생성하지 않고 한 번에 답을 내는 오픈웨이트 결정 모델 2종

- **원문:** https://www.liquid.ai/blog/d1-open
- **분야:** 모델 · 오픈웨이트/엣지
- **날짜:** 2026-10-07

### 요약

Liquid AI가 **결정 모델(decision model, 글을 생성하지 않고 분류·선택·점수 같은 정해진 형태의 답을 내는 모델)** 제품군의 오픈웨이트 2종 **d1-3B** 와 **d1-omni-600M** 을 허깅페이스에 공개했습니다. 일반 생성형 모델과 달리 출력 토큰을 만들지 않고 **한 번의 순전파(forward pass, 모델을 한 번 통과시키는 계산)** 로 답을 냅니다.

d1-3B는 자사 비전 언어 모델 LFM2.5-VL-3B를 바탕으로 텍스트·이미지를 받고, d1-omni-600M은 양방향 인코더 LFM2.5-Encoder-350M에 비전·오디오 인코더를 붙여 "텍스트+이미지" 또는 "텍스트+오디오"를 받는 첫 실험 체크포인트입니다. 회사 발표 기준 d1-3B는 Decision Index v0.2.1(공개 분할)에서 48.57점으로 10B 미만 모델 중 최고이며 12배 큰 Decider 35B-A3B와 비슷하고, 7개 텍스트 벤치마크 평균 82.9로 Decider 4B(81.1)를 앞섭니다.

속도도 강조했습니다. d1-3B는 질문 하나에 RTX 4090에서 8ms, Jetson AGX Thor 16ms, Jetson AGX Orin 26ms, 가장 작은 Jetson Orin Nano에서도 50ms가 걸립니다. 출시 첫날부터 llama.cpp를 지원하며(엔진 브리핑 2번), 크립토포스트 보도에 따르면 라이선스(LFM Open License v1.0)는 연매출 1,000만 달러 미만 기업의 상업적 사용을 무료로 허용합니다.

**시사점:** 콘텐츠 모더레이션, 카메라 기반 실시간 판단, 로봇 같은 엣지 기기에서 "생성 없이 빠른 판단"을 하는 작은 모델이 하나의 범주로 자리 잡고 있습니다.

## 3. Perplexity 'pplx-embed-v2-late' — 텍스트·이미지·PDF 페이지를 OCR 없이 검색하는 오픈 임베딩

- **원문:** https://community.perplexity.ai/t/were-releasing-pplx-embed-v2-late-two-late-interaction-embedding-models-that-retrieve-text-images-and-pages-with-a-shared-embedding-space-for-cross-model-querying/6296
- **분야:** 모델 · 오픈웨이트/임베딩
- **날짜:** 2026-10-07

### 미디어

![pplx-embed-v2-late 공개 (Crypto Briefing 기사 대표 이미지)](https://static.cryptobriefing.com/wp-content/uploads/2026/10/07121352/library-perplexity-ai-releases-pplx-embed-v2-late-models-for-mul-800x450.png)

> 출처: Crypto Briefing 관련 기사 (https://cryptobriefing.com/perplexity-pplx-embed-v2-late-multimodal-models/) — 원본 이미지 링크(복제 저장 아님)

### 요약

Perplexity가 0.6B·9B 두 크기의 멀티모달 **임베딩 모델(embedding model, 문서·이미지를 검색용 숫자 벡터로 바꾸는 모델)** **pplx-embed-v2-late** 를 허깅페이스에 공개했습니다. 텍스트, 이미지, PDF·슬라이드 같은 시각 문서를 검색할 수 있고, 렌더링된 PDF 페이지를 **OCR(이미지 속 글자 인식)** 없이 그대로 다룹니다.

이름의 'late'는 **후기 상호작용(late interaction, 문서를 벡터 하나로 뭉치지 않고 토큰마다 작은 벡터를 남겨 두었다가 검색 시점에 질의와 세밀하게 비교하는 방식, ColBERT 계열)** 을 뜻합니다. 토큰별 128차원 벡터를 유지하고 MaxSim(질의 토큰마다 가장 비슷한 문서 토큰 점수를 더함)으로 점수를 매깁니다. 두 모델은 **임베딩 공간을 공유** 해, 9B로 색인한 문서 모음을 더 빠른 0.6B로 질의할 수 있다는 점이 특징입니다.

Perplexity는 올해 초 단일 벡터 방식 pplx-embed-v1, 이어 문맥형 v2 모델을 낸 데 이어 이번에 멀티모달로 범위를 넓혔고, 두 모델 모두 "최전선 수준 성능"이라고 밝혔습니다(회사 발표).

**시사점:** 표·그림이 섞인 사내 문서를 OCR 파이프라인 없이 검색하는 RAG(검색 증강 생성) 구성에 쓸 만한 오픈 선택지가 늘었습니다.
