## 1. MCP 두 돌 — Skills over MCP(베타)와 Tasks·Elicitation 정식 출시

- **무슨 일인가:** Anthropic이 11월 24일 "MCP 서버가 이제 스킬을 싣고, 태스크를 실행할 수 있다"는 글을, Model Context Protocol 프로젝트가 같은 날 2주년 회고를 각각 발표했다. 핵심은 셋. ① Skills over MCP(공개 베타): MCP 서버가 도구와 함께 스킬(여러 단계 작업을 위한 지시문 패키지)을 제공할 수 있게 됐다. 스킬은 필요할 때만 로드되고 서버와 함께 업데이트된다. Claude와 Claude Code에서 Pro/Max/Ultra는 기본 활성, Team은 관리자 설정, Enterprise는 추후. 출시 파트너는 Shopify, HubSpot, Atlassian이고 Carta가 뒤따른다. ② Tasks(정식): 서버가 긴 작업을 백그라운드에서 실행. ③ Elicitation(정식): 서버가 폼이나 링크로 사용자 입력을 요청. 파일을 컨텍스트 윈도우를 거치지 않고 서버에 넘기는 File Uploads는 곧 출시 예정. 확장들은 오픈 MCP 사양의 일부라 다른 클라이언트도 지원할 수 있다. (llmnet 데일리 2026-11-25 = 구간 경계; llmnet이 Anthropic 글과 MCP 블로그 두 페이지를 직접 읽은 1차 소스 기반, 신뢰도 high)
- **논조:** "서버가 자기 작업 지시문을 직접 배포할 수 있게 돼 별도 프롬프트나 플러그인이 필요 없어졌다"는 구조 변화로 정리된다.
- **다른 시각:** 서버가 싣는 스킬은 곧 실행 지시문이다. 신뢰할 수 없는 서버의 스킬은 프롬프트 인젝션의 새로운 통로가 될 수 있어, 서버 선택과 검토가 더 중요해진다.
- **시사점:** 어제 GitHub 트렌드를 덮은 '스킬 번들' 흐름이 프로토콜 차원에서 정규화됐다. 에이전트 생태계의 표준 경쟁이 도구 연결(MCP 1년차)에서 작업 패키지 배포(2년차)로 옮겨가는 신호다.

## 2. OpenAI, 수학 원고 9편을 GitHub에 공개 — "VP≠VNP", "행렬곱 지수 9/4" 등 대형 주장, 독립 검증 없음

- **무슨 일인가:** openai/math GitHub 저장소의 history 파일에 따르면, 11월 23일자로 원고 'VP and VNP are different'(페이지 기준 11월 6일에 얻은 결과)가, 11월 24일자로 두 계열의 새 원고 9편이 올라왔다. 제목에는 'The matrix multiplication exponent is nine fourths'(행렬곱 지수 9/4=2.25, 현재 알려진 최선보다 낮은 값), 'Strongly polynomial linear programming'(OpenAI 주장으로는 결정적 강다항식 LP 알고리즘 — Smale의 9번 문제에 대한 답), 'Superpolynomial graph diameter of simple polytopes' 등이 있다. 페이지는 일부 결과의 Lean 형식화를 포함한다고 밝히지만 'VP≠VNP'에는 해당 목록이 없고, 저자·피어리뷰·발견 과정에 대한 설명도 없다. llmnet은 신뢰도를 low~medium으로 매기며 "독립적 확인이 없고 수학의 정확성을 판단하지 않았다"고 명시했다. Hacker News의 'VP ≠ VNP before Anthropic'이라는 제목(86포인트)은 포럼 사용자의 헤드라인일 뿐 확인이 아니다. The Neuron도 행렬곱 지수 9/4 프리프린트를 보도하며 "독립 검증이 된다면"이라는 단서를 달았다. (llmnet 데일리 2026-11-25 = 구간 경계, history.md를 llmnet이 직접 읽음; The Neuron 2026-11-25 = 정규 구간 내)
- **논조:** OpenAI의 공개 자체는 사실이나, 내용의 정확성은 전면 미검증. llmnet은 "수학자들이나 형식 검증을 기다려야 한다"고 권고한다.
- **다른 시각:** 리만 가설 건과 달리 이번에는 공동 성명도, 외부 커널 검증 로그도 없다. 특히 VP≠VNP는 복잡도 이론의 가장 큰 미해결 문제 중 하나라 주장의 무게가 다르다.
- **시사점:** 'AI가 미해결 수학 문제를 푼다'는 서사의 두 번째 시험대다. 첫 사례(리만)가 커뮤니티 검증을 단계적으로 통과한 것과 비교하면, 이번 건은 검증 인프라 없이 먼저 공개된 형태다. 결론 보류가 합리적이다.
