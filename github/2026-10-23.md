**어떻게 쓰나** — 공식 패키지 설치 뒤 모델 제공자와 모델을 지정하고, 작업 변경분에는 ocr review, 파일 전체에는 ocr scan을 쓰는 흐름이다. 위임 모드는 별도 모델 연결 대신 호스트 에이전트를 사용할 수 있다. 실제 도입 전에는 작은 공개 예제나 비민감 코드로 결과 위치와 오탐 여부부터 비교하는 편이 좋다.

**비슷한 도구와 비교** — [Semgrep](https://github.com/semgrep/semgrep#readme)는 규칙으로 코드를 검색·분석하는 정적 분석 도구다. Open Code Review는 파일 묶음과 검토 위치를 프로그램으로 관리하면서 언어 모델이 맥락을 해석한다. 어느 쪽이 더 정확한지는 프로젝트·규칙·모델에 따라 직접 검증해야 하며, 둘을 같은 종류의 검사로 간주하지 않는 편이 좋다.

**주의할 점** — 2026-05-18 생성, Apache-2.0, 열린 항목 342개다. README의 토큰 약 1/9 및 정밀도 우위는 자체 벤치마크 주장이고, 재현율은 낮다는 제한도 함께 명시돼 있다. 모델 제공자에게 코드가 전송되는 구성을 먼저 검토해야 한다. 별 +225는 품질 검증이 아니며 결함 탐지 누락 가능성을 없애지 않는다.
