### [HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything)

 ⭐ 59,655 · 📈 +384 일간 · ⚖️ Apache-2.0 · 🗓️ 생성 2026-03-08 

![HKUDS/CLI-Anything 대표 이미지](https://opengraph.githubassets.com/1/HKUDS/CLI-Anything){: .gh-img loading="lazy"}

임의의 소프트웨어를 에이전트가 다룰 수 있는 CLI로 변환하는 생성기.
{: .gh-lead}

**무엇인가** — "모든 소프트웨어를 에이전트 네이티브로(Making ALL Software Agent-Native)"를 표방하는 프로젝트. 기존 소프트웨어(GIMP 같은 GUI 프로그램 포함)를 분석해 에이전트가 호출할 수 있는 완성된 CLI를 7단계 과정으로 생성해준다. 홍콩대 데이터 과학 연구실(HKUDS)의 프로젝트로, Claude Code 플러그인·스킬 등 여러 에이전트 플랫폼용 설치 경로를 제공하고, 생성된 CLI 모음 허브(CLI-Hub, clianything.cc)도 운영한다.

**왜 지금 뜨나** — 관측 일간 +384로 목록에 새로 들어왔다. 2026년 3월 생성 저장소로 신작은 아니다. '에이전트가 기존 소프트웨어를 쓰게 만드는' 부류의 관심이 스킬·하네스 강세와 맞물려 있다. 직접적인 촉발 이벤트는 확인되지 않았다.

**어떻게 쓰나** — Claude Code라면 마켓플레이스에서 cli-anything 플러그인을 설치한 뒤 `/cli-anything <소프트웨어 경로나 저장소>`를 실행하면 된다. 생성된 CLI를 PATH에 설치하거나 REPL로 띄워 에이전트가 사용한다.

**비슷한 도구와 비교** — GUI 자동화(좌표 클릭) 방식의 컴퓨터 사용 에이전트와 달리, 소프트웨어를 CLI로 '번역'해 에이전트 친화적으로 만드는 접근이다. README는 이를 'GUI 에이전트의 대체 또는 증강'으로 설명한다.

**주의할 점** — 생성된 CLI는 대상 소프트웨어의 기능을 자동화 권한으로 여는 셈이므로, 파일 시스템을 건드리는 프로그램에 적용할 때는 실행 범위를 먼저 제한해야 한다. 이번 브리핑은 설치·실행 시험을 하지 않았다.
{: .gh-warn}

### [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)

 ⭐ 3,670 · 📈 +323 일간 · ⚖️ Apache-2.0 · 🗓️ 생성 2026-06-24 

![NVIDIA/SkillEvaluator 대표 이미지](https://opengraph.githubassets.com/1/NVIDIA/SkillEvaluator){: .gh-img loading="lazy"}

에이전트 스킬·플러그인의 품질과 보안을 단계별로 검증하는 NVIDIA의 평가 프레임워크.
{: .gh-lead}

**무엇인가** — AI 에이전트의 스킬과 플러그인을 평가하는 다단계 프레임워크. 품질 게이트, 스킬 간 의미 중복 탐지(semantic overlap detection), 합성 평가 데이터셋 생성, 그리고 스킬이 에이전트 행동에 미치는 영향을 측정하는 라이브 에이전트 평가까지 단계를 나눠 검증한다. 보안 스캐너 토픽(security-scanner)도 붙어 있다.

**왜 지금 뜨나** — 관측 일간 +323으로 첫 등장. 스킬 부류(Claude-BugHunter·superpowers·ECC)의 연속 강세 속에 '쌓기' 다음 단계인 '검증하기' 수요가 표면화된 것으로 읽힌다. NVIDIA 공식 저장소라는 점도 주목 요인이다. 직접적인 촉발 이벤트는 확인되지 않았다.

**어떻게 쓰나** — Python 기반이며 Dockerfile과 Makefile을 제공한다. 문서 사이트(docs.nvidia.com/skills/skillevaluator)가 별도로 있다.

**비슷한 도구와 비교** — superpowers·ECC가 스킬을 '공급'하는 쪽이라면 SkillEvaluator는 스킬을 '심사'하는 쪽이다. 같은 생태계의 수요와 공급이 한 주에 같이 튄 셈이다.

**주의할 점** — 평가 프레임워크 자체가 에이전트를 라이브 실행하므로, 평가 대상 스킬의 코드도 샌드박스 안에서만 다뤄야 한다. 열린 이슈 67건(관측 시점). 실행 시험은 하지 않았다.
{: .gh-warn}
