- **hindsight** — "배우는 에이전트 메모리". 에이전트가 과거 상호작용에서 얻은 정보를 저장·회상하고 경험으로부터 개선하도록 돕는 **장기 메모리(long-term memory, 세션이 끝나도 유지되는 기억)** 계층. 주간 1만 개 이상 급등.
- **paperclip** — 업무에서 여러 에이전트를 관리하는 오픈소스 앱. 에이전트를 "직원"처럼 배치·감독하는 **오케스트레이션(orchestration, 여러 작업 주체를 조율)** 도구.
- **Agent-Reach** — AI 에이전트가 트위터·레딧·유튜브·깃허브·빌리빌리·샤오홍슈를 읽고 검색하게 해주는 CLI. 별도 **API 요금(유료 접근 키)** 없이 하나의 명령줄 도구로 통합.
- **openrig** — Claude Code·Codex·Pi 같은 코딩 에이전트들로 역할·공유 컨텍스트·담당 업무를 가진 **지속형 팀(persistent team)** 네트워크를 구성.
- **claude-mem** — 에이전트 세션 중 일어난 일을 기록·AI로 압축한 뒤, 다음 세션에 관련 내용을 다시 주입하는 **세션 간 지속 컨텍스트** 도구.
- **caveman** — "적은 토큰으로 충분하다". 코딩 에이전트가 원시인처럼 짧게 말하게 해 **토큰(token, 모델이 처리하는 텍스트 단위 = 비용 단위)** 을 약 65% 줄인다는 스킬+프록시.
- **OpenShell (NVIDIA)** — 자율 AI 에이전트를 위한 안전하고 사적인 **런타임(runtime, 프로그램이 실제로 실행되는 환경)**. 에이전트 실행을 격리·통제하는 샌드박스 성격.
- **cloudflare-os** — Cloudflare Workers 위에서 회사 맥락·시스템과 연결해 문서 작성, 앱 빌드, 에이전트 실행을 하는 **에이전트 워크스페이스**.
- **text-to-cad** — 에이전트에 **CAD(컴퓨터 지원 설계, 3D 부품·도면 설계)** 능력을 부여. 자연어로 3D 모델 생성.
- **impeccable** — AI **하네스(harness, 에이전트 실행 틀)** 의 디자인 감각을 높여주는 "디자인 언어" 규칙 모음.
